# 新生児の抱っこ表示契約

## 目的

0歳の birth / village フェーズでは、プレイヤー本人を成人キャラクターとして誤読させず、「養育者に抱かれている新生児」と一目で判別できる表示を保証する。

## 表示契約

- birth / village 中だけ養育者を表示し、新生児は養育者の胸前かつカメラから読める位置に固定する。
- 新生児は既存の infant 年齢スケールを維持し、抱っこ中は横向きの姿勢として表示する。
- 養育者モデルに含まれる武器・盾・弓・矢筒などの戦闘用プロップは birth 表示では非表示にする。
- 抱っこ中の養育者は移動状態に応じた揺れを許容するが、戦闘姿勢・戦闘エフェクトへ遷移させない。
- birth を抜けたら養育者を非表示にし、プレイヤーの回転・位置・通常装備表示を既存挙動へ完全に戻す。

## 不変条件

- 年齢進行、life / zone / phase の正本、入力、HUD、装備データそのものは変更しない。
- 0歳プレイヤーに新しい武器装備を与えない。
- 成人・敵・協力プレイヤーの既存表示契約を変更しない。
- 新しいランタイム依存や追加ネットワーク取得を導入しない。

## 回帰確認

1. `phase=birth`, `zone=village` で養育者が見え、新生児が胸前で読めること。
2. birth 中の新生児が横向きで、養育者の戦闘用プロップが非表示であること。
3. birth 終了後にプレイヤー姿勢が直立へ戻り、養育者が消えること。
4. 既存の年齢スケールと装備同期が維持されること。
