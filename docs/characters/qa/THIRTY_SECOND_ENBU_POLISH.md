# 30秒演武 polish

## 目的

Character Motion QA の既存30秒列を、検査用の時間配分や実ゲームの攻撃時計を変えずに、全身の演技として読みやすくする。

今回の改善対象は 17.0〜23.0 秒の `authored-slash`。同じ共有斬撃ソースを使う実ゲーム側にも改善を返し、Visual Review 専用の別モーションは作らない。

## 不変条件

- 30秒列の `idle / walk / run / draw / guard / slash / sheathe / idle-end` の区間は維持する。
- 斬撃は 0.66 秒、`active=[0.35,0.64]`、`contact=0.50`、`launch=0.34`、`plant=0.49`、`chain=0.86` を維持する。
- gameplay の actor x/z、攻撃判定、ダメージ、接触時計、controller-owned warp の責務を変更しない。
- 始端と終端は通常の sword guard と連続させる。
- カメラ、画面揺れ、VFXで身体の弱さを隠す改善は行わない。

## 改善方針

1. 溜めでは重心を落とし、骨盤と胸郭の向きに差を作り、次の斬撃方向を全身で予告する。
2. 打点では支持脚へ重さが乗り、骨盤から胸、肩、剣へ順に力が抜けるシルエットを強くする。
3. 振り抜きでは剣だけを走らせず、頭部の視線、胸郭、骨盤、後脚の解放を連動させる。
4. 戻りでは勢いを殺して直立へ瞬間復帰せず、次の一撃へ渡せる制動を残す。
5. free hand は胴体へ貼り付かず、斬撃中も防御と釣り合いの役割が読める位置を保つ。

## 受入条件

- 既存 slash clock / seam / socket / planted-foot / forward-knee のテストを維持する。
- 新しい回帰テストで、溜めの低重心、打点前後の胴体回旋差、斬撃加速、振り抜き後の制動を数値的に固定する。
- 数値テストは見た目承認の代替にしない。Ready 後の DEV 30秒レビューで 1x 再生を確認対象とする。
- `SLASH_REVISION` を更新し、Motion QA report が変更後 revision を追跡できるようにする。
