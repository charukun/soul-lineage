# MURA 会話・発話共通契約

`apps/village` と `apps/rinne` が同じ村を扱うとき、施設の意味や暮らしの事実を各appへ重複ハードコードしない。世界に属する事実は `@soul/world/mura` を正本とし、各appはその事実から自分の話者・演出に合う文章を組み立てる。

## 共通化するもの

- 施設ID / label / trait / effect など、村そのものに属する意味。
- 発話で使える共通topic IDと短い意味文。
- プレイヤーが選べる定型発話の intent ID。表示文はlocale/presentation側で差し替え可能にする。

## app側に残すもの

- 母、村人、プレイヤーなど話者固有の口調・呼び方・語尾。
- 吹き出し、dialogue panel、音声入力、扇メニュー等のUIと表示タイミング。
- ゲーム固有の反応・進行・報酬。

`apps/rinne` から `apps/village` を直接importせず、双方が共有packageを参照する。

## Rinne本編の発話UI

- 0〜4歳の出生期は母・NPCからの自発会話だけで進み、プレイヤー発話UIを出さない。
- 4歳以降の能動発話は、旧「話す」ボタンではなく、マイク入力と定型文の扇メニューを同じ発話経路へ流す。
- マイク権限はユーザー操作時だけ要求し、音声認識が使えないWeb環境でも扇メニューだけで操作可能にする。
- 認識テキストや定型文の選択はまずローカルの発話イベントとして扱い、未実装のserver/AI会話が成功したことにしない。

## 出生期の施設案内

母の施設案内は共有MURA施設メタデータを根拠にし、Rinne側に施設用途の別コピーを持たない。学校内の「本を読む」など同一施設内の副topicだけは共通topicとして明示し、施設traitと矛盾しない短い母親口調へ整形する。
