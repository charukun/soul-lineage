# 建物の出入りと室内座標

輪廻転焦 (`apps/rinne`) と村 (`apps/village`) は、建物の入口・壁・室内判定を個別実装せず `@soul/world/mura` の共通ジオメトリ契約を正本にします。

## 契約

- 建物のローカル座標は右手系 Y-up、入口はローカル `+Z` 側の中央です。
- 完成済みの閉鎖建物は、建物全体を通行不可にせず、外周壁だけを衝突対象にします。入口幅の範囲では外側から室内へ連続して歩いて通過できます。
- 室内は建物のローカル矩形として判定し、回転した建物でも同じ変換を使用します。
- `open` な施設は従来どおり建物壁の衝突対象にしません。
- 建物が移動して保存位置と重なった場合の安全位置復旧は、共通の壁・入口判定を使います。
- アプリ固有のカメラ、屋根のカットアウェイ、選択UIは各アプリが所有できますが、入口位置・室内判定・world/local変換を再定義しません。

## 受入条件

1. 輪廻転焦のプレイヤーが、村長テントを含む完成済みの閉鎖建物へ入口から歩いて入り、同じ入口から外へ戻れること。
2. 入口以外の壁は通り抜けられないこと。
3. 回転した建物でも入口と壁の判定が追従すること。
4. 村アプリの室内編集・家具配置が同じ入口向きと world/local 座標変換を使用すること。
5. 共有村レイアウトの既存 schema と各アプリの独立した entry point を維持すること。
