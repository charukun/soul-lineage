# 建物の出入りと室内座標

百年転生 (`apps/rinne`) と村 (`apps/village`) は、建物の入口方向・壁・室内通行判定を個別に食い違わせず `@soul/world/mura` の共通ジオメトリ契約を正本にします。

## 契約

- 建物のローカル座標は右手系 Y-up、入口はローカル `+Z` 側の中央です。
- 完成済みの閉鎖建物は、建物全体を通行不可にせず、外周壁だけを衝突対象にします。入口幅の範囲では外側から室内へ連続して歩いて通過できます。
- 室内通行は共通の入口・壁契約に従い、家具配置の有効床面は建物の実形状に合わせる。通常建物はローカル矩形、テント/ゲルは円形床を使い、回転した建物でも同じ変換規約を使用します。
- 家具配置は実際の家具footprint・住宅サイズ・入口幅を使って判定し、壁へのめり込み、大型家具の小型ゲルへの持ち込み、入口から室内中央までの動線遮断を許可しません。
- 視覚上の入口も共通のローカル `+Z` 契約に合わせ、テント/ゲルを含む閉鎖建物は遠景でも入口位置が読めること。
- `open` な施設は従来どおり建物壁の衝突対象にしません。
- 建物が移動して保存位置と重なった場合の安全位置復旧は、共通の壁・入口判定を使います。
- アプリ固有のカメラ、屋根のカットアウェイ、選択UI、表示用 footprint は各アプリが所有できますが、入口方向・壁・室内通行判定は共通契約に従います。

## 受入条件

1. 百年転生のプレイヤーが、村長テントを含む完成済みの閉鎖建物へ入口から歩いて入り、同じ入口から外へ戻れること。
2. 入口以外の壁は通り抜けられないこと。
3. 回転した建物でも入口と壁の判定が追従すること。
4. 宝満叡智の住人移動と室内状態が同じ入口向き・壁・室内判定を使用すること。
5. 共有村レイアウトの既存 schema と各アプリの独立した entry point を維持すること。
