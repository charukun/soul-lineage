# 一族はプレイヤーに根付く

- 一族は通常プレイで作り直さない。初回の一族決定後は、Continueと転生を通して同じ一族IDを維持する。
- 人生は一族の一世代。村は住む場所であり、一族そのものではない。
- 別の村へ出生した時は一族の移住として履歴に残す。一族の起源・家風・最初の家伝は変えない。
- 家伝は技の排他ロックにしない。初期家伝は関連技へ小さな縁を与えるだけで、他家でも必要な経験を積めば同じ技へ到達できる。
- 各世代が覚えて生涯を終えた技は一族の技譜へ蓄積する。同じ技を複数世代が持ち帰るほど縁が強まり、3世代以上で「家伝として定着」とみなす。
- 技譜は次世代へ技そのものを自動付与しない。閃き候補の優先度だけを押し上げ、必要な経験・問い・装備・年齢条件は維持する。
- 通常タイトルから「新しい一族でやり直す」は出さない。保存がある場合はContinueを正規導線とする。
