# 一族問答の演出境界

- 既存の百年転生オープニングムービーとタイトル画面を一族UIで上書きしない。
- 一族問答はタイトルの「はじめる」を選んだ後だけ開始する。「続きから」は問答へ入らない。
- 問答はWebページではなくゲーム内の儀式シーンとして構成する。水、記憶、血脈、家伝を、奥行き・光・波紋・粒子・選択反応・遷移アニメーションで表現する。
- 四角いカード型レイアウトを主役にせず、記憶の珠／紋／祭具として選択肢を見せる。
- タイトルBGMを壊さず、問答中は専用の低い水音・脈動・選択音・確定音を重ねる。ゲーム開始時に通常のゲーム音へ戻す。
- reduced-motion、キーボード操作、保存上書き確認、取消、既存セーブ保護を維持する。
