# 百年転生：水底の問答と一族の起源

初めての人生を始める前に、水中の魂へ触れる短い問答で「文化・家風・お家芸」を選ぶ。性格の優劣判定や職業の強制ではない。

## 体験

- 青緑の水、差し込む光、小さな魂、指に反応する流れと波紋。溺れる表現は使わない。
- 景色、家の言葉、受け継ぐ品の三問。短い日本語と情景・品物を使用し、説明文や四角い設定カードを主役にしない。
- 和の山里と刀の家伝を選べる。文化と家風とお家芸は独立し、正解や強弱はない。
- 確定前に家紋・家の情景・家宝・家族を見せ、「この家に、生まれる」で既存の誕生体験へつなぐ。戻って選び直せる。
- 中断した未確定の問答は復帰できる。既存の人生の保存データを暗黙に消さない。
- 続きからは問答を挟まず、保存された一族・現在の人物・年齢・進行を再開する。
- 新しい一族の作成は既存セーブの置換を明示確認する。キャンセルと保存失敗では既存セーブを維持する。

## ゲームとの接続

- 一族の起源は人生のセーブに格納し、転生・再読込で引き継ぐ。
- 既存セーブは互換移行し、問答を強制しない。初回出生村のランダム選択と故郷解放条件は変更しない。
- 家伝は暮らし・稽古・家族の言葉と系譜で表現する。幼少期や7歳の武具解禁を飛ばさず、既存の武器選択・能力・閃きの因果を制限しない。
- 家伝と各世代の記録を一族の画面へ接続する。世代ごとの能力は従来どおりリセットする。
- 保存済みの一族があるタイトルでは、その家の情景と家紋を表示する。

## 検証

純粋な問答・正規化・保存復元・転生・既存セーブ互換のテスト、既存の人生domain回帰、およびrinneのbuildをexact-headのGitHub Actions hosted runnerで実行する。水中UIは既存browser/evidence経路を利用し、スマホとデスクトップ、キーボード、reduced motion、途中再読込、確定、続きから、キャンセル、保存失敗を確認する。
