# 輪廻転焦 本編プレイスルーUX

現行 `apps/rinne/src/rebuild/` を本編の操作正本とし、初見プレイヤーが外部説明なしで一生を進められることを受入条件にする。

## 基本ループ

1. 出生。母と村を歩き、4歳までに移動・会話と村の存在を知る。
2. 村で成長。暮らしの場所を巡り、経験・技・武具を知る。
3. 7歳以降に武具を選び、15歳以降の出航条件と港を理解する。
4. 港から前線へ出立。敵に接近すると自動戦闘になることを画面内で理解する。
5. 前線を突破し、さらに奥へ進む。最終前線では帰還地点を明示する。
6. 行動不能なら救助で村へ戻る。突破できれば凱旋して村で次の出航を待つ。
7. 寿命を迎えたら生涯の記録を確認し、記憶を選んで次の自分へ転生する。

## UI受入条件

- 常時HUDは「現在の段階・短い目的・方向/距離」を中心にし、説明文を常設しない。
- 生活行動・装備変更・出航・戦闘など、近接や停止で自動発火できる行動にはコンテキストボタンを追加しない。原因と結果は短い状態表示・トースト・演出で伝える。
- コンテキストボタンは自動化できない任意操作だけに限定する。現行では会話を基本とし、対象が近くにいない時は隠す。不可逆な選択や明示確認が必要な場面は個別UIで扱う。
- 年齢や条件の解禁は長文で説明せず、必要な時だけ短いロック/年齢表示や目的の変化で示す。
- 目的地がある場合は方向と距離を表示する。目的地付近で自動発火する行動はボタンではなく、短い動詞または状態名で予告する。
- 年齢待ちだけの時間を作らず、待機中は村の目的地を示す。操作説明は初回・状態変化時の短い表示に留める。
- 前線は「敵 → 奥 → 帰還」の方向を画面から読み取れる。攻撃ボタンは置かず、敵への接近で自動戦闘する現行仕様を維持する。
- 行動不能時は救助までの残りを簡潔に示し、救助・帰還そのものにボタンを要求しない。
- 100歳時は転生がゲームループの続きであることを示し、継承内容を確認できる。転生のような不可逆な選択は明示ボタンを維持する。
- 390x844相当の縦画面で主要情報が重ならず、中央のプレイ領域を塞がない。

## 検証

ドメインテストに加えて、Playwrightでタイトル → 新生 → 村生活 → 武具 → 出航 → 前線 → 凱旋/救助 → 寿命 → 転生の主要導線を実UI経由で通す。保存データの直接注入は長時間待機を短縮する補助に限定し、目的表示・操作可能性・遷移結果は実画面で確認する。

追加で、生活・装備・出航・戦闘に専用のコンテキストボタンが増えていないこと、会話ボタンが近接対象なしで常駐しないこと、通常HUDに長い説明文を置かないことをブラウザ検証する。
