# 百年転生: 生まれる前の問答

初めての一族を、静かな水中で魂が記憶に触れる三つの問答から形にする。土地、家風、お家芸は独立した選択で、和の一族と刀を組み合わせられる。最後に家紋と家伝を見て「この家に、生まれる」で確定する。途中で選び直せる。

## 受入条件

- 初回の「はじめる」から水中問答へ入り、短い問いと触れられる記憶、波紋、光、浮遊感で進める。モバイル、キーボード、reduced-motionに対応する。
- 家の系統は確定時に保存され、続きからは同じ人物・年齢・世代・進行を再開する。再起動や次世代で問答を強制しない。
- 旧セーブは消さず、既存の人生と操作、成長、幼少期、武具解禁条件を維持する。上書きは既存の確認経路を守る。
- 一族の家風・お家芸は系譜と暮らしに表示し、家伝の稽古につなぐ。武器選択を固定せず、初回ボーナスの重複付与を防ぐ。
- 新しい一族を始めるとき以外は同じ家の根を引き継ぎ、タイトルから自分の家へ帰れる入口にする。
- 一族設定、保存復帰、旧データ互換、選択取消、次世代継承をfocused testで検証し、rinneをbuildする。既存のActions品質gateや常設処理は増やさない。
