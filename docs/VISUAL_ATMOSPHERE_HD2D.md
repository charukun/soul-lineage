# Rinne / Village atmosphere target

Reference direction: a compact isometric diorama with a quiet, lived-in mood. This is an atmosphere target, not a request to copy another game's assets or exact composition.

## Acceptance

- Keep the current gameplay, save data, interaction model, camera controls, and app boundaries unchanged.
- Rinne and Village should feel related through cool environmental fill, warm local light, restrained mist/haze, miniature depth separation, and darker edge framing.
- Rinne remains the more dramatic adventure presentation. Village remains the softer life-sim presentation.
- Do not replace authored models with generated reference imagery or bake a screenshot into the game.
- Preserve adaptive rendering and reduced-motion/accessibility behavior.
- Pixel-art rendering is not required. The target is the mood and spatial readability of HD-2D / miniature diorama presentation using the existing 3D renderer.
