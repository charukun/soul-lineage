# 3ゲーム App Icon System

`rinne` / `village` / `demon` の favicon と installable Web App icon は、各ゲーム固有の世界観を一つの単純なシンボルへ圧縮する。

## 共通ルール

- 小さい favicon でも輪郭を判別できる単純な形を優先する。
- 文字、細い装飾、写実的な描き込み、汎用的な「ゲームっぽい紋章」を避ける。
- 3ゲームは同じ角丸スクエアの骨格を共有しつつ、色と中心記号で即座に識別できるようにする。
- favicon と `manifest.webmanifest` の app icon は同じ中心記号を使う。
- Android の maskable icon と通常アイコンの両方で重要な形が欠けないよう、主要記号は中央の safe zone に収める。

## rinne / 100年人生 — 輪廻転焦

テーマは「暮らし、戦い、遺し、また生まれる」。閉じ切らない二つの円弧が世代の循環を表し、中央の小さな焦点が一つの人生を示す。墨に近い深緑と、淡い象牙＋小さな琥珀の焦点で現代的にする。

## village / MURAAAAAAA

テーマは「暮らしと守りが、道をつくる」。家そのものではなく、村を囲う輪郭と外へ続く一本の道を記号化する。落ち着いた苔色に生成りの輪郭、道だけを土色のアクセントにする。

## demon / 尽喰廻遊

テーマは「喰らい尽くせ。夜は、まだ廻る。」。夜を巡る捕食の循環を、欠けた赤い円と一つの牙で表す。黒に近い夜色、鈍い血赤、牙だけを骨色にして、細かな目・角・紋様は使わない。

## Acceptance

- 各 app のブラウザ favicon が新シンボルを参照する。
- 各 `manifest.webmanifest` の `icons` が同じデザインの `app-icon.svg` を参照する。
- 48px 相当まで縮小しても中心記号を識別できる。
- 3つを並べたとき同一シリーズ感があり、単体ではゲームを見分けられる。
