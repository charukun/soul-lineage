# 尽喰廻遊 — 狩りと帰還のループ

2026-09-18 のユーザー依頼に基づく更新。対象は `apps/demon` の単独狩り。巨大化の早さ、強さの実感の不足、説明過多、死亡後の迷い、生還メリットの不明瞭さを解消する。

## 受入条件

- 狩る → その夜の成長 → 帰還で恒久強化 → より危険な狩場、のループを実ゲームへ接続する。
- 見た目の成長と攻撃力の成長を分離し、数体の捕食だけで巨大化を完了させない。攻撃強化は既存 Tidebreak の技データへ反映し、独自戦闘へ置換しない。
- 生還時の確定報酬と死亡時の持ち越しを明示する。何も狩らず帰る、設定画面から撤退する、重複結果処理による報酬稼ぎを防ぐ。
- 既存の特能・転生史・訪問台帳は保持する。新規の恒久成長は後方互換の app 固有拡張とし、破損時は上書きしない。
- 狩り中は短い次の目標だけを表示する。初回説明を重ねず、詳細は任意で開く。
- 死亡後は失ったもの・残ったもの・次の行動を同じ画面に置き、明確な再挑戦ボタンを提供する。
- 成長曲線、帰還/死亡/中断の精算、再読込と重複、既存保存互換を局所テストする。

## 変更しない境界

輪廻転焦・MURAAAAAAA・共有戦闘の序破急/間合い/接触判定・オンライン authority・入村IDの再訪防止・main/Productionは変更しない。実機プレイ確認とコード上の検証を区別して報告する。
