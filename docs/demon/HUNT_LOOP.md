# 喰滅廻遊 — 狩りと帰還のループ

2026-09-18 のユーザー依頼に基づく `apps/demon` 単独狩りの刷新。巨大化の早さ、強さの実感の不足、説明過多、死亡後の迷い、生還メリットの不明瞭さを対象とする。

## 実装したループ

狩る → 未確保の戦利品とその夜の成長 → 物理的な帰還 → 恒久強化 → 次の標的。

初回は小規模の村で2体を捕食して帰還する。旅人2体なら戦利品4と目標報酬6で計10。最初の強化は8なので、牙・骨・足から一つを購入できる。次の目標は鐘番、猟師、鍛冶師、術師、守護騎士へ進む。死亡後の主動線は、近場で2体を持ち帰る安全寄りの立て直し。弱い獲物をプレイヤーに合わせて強化しない。

- 牙: Tidebreakが実際に使用するrecipe tempoを段階強化する。表示は「技速」であり、架空の攻撃力倍率やDPS保証ではない。
- 骨: 基礎生命を1段階18増やす。
- 足: 移動速度を1段階7%増やす。

費用は段階的に上昇し、牙・骨は4段階、足は3段階で止まる。基礎生命、獲得済み特能、技の選択は既存の仕組みを生かし、獲物の名指し特能を確実に得られるようにする。狩りの目標は同じ村への再入場を作らず、必ず新規の正式な村IDをclaimする。

体格は24捕食で上限に達する緩やかな線形成長へ分離した。夜魔は0.65から1.45で、3体以内に巨大化しない。生命と技速は最初の捕食から増える。種族はプロフィールIDから安定して選び、既存の明示選択を優先する。初回と立て直しでは生成村の入口寄りの一般武装者だけを弱い獲物へ置き換える。奥の脅威、標的、インポート村は変更しない。

## 帰還と保存

未確保の戦利品はセッション内に置く。生還精算には捕食1体以上、帰還口2.8m未満、戦闘・捕食中でないこと、1.6秒を超える停止が必要。目標未達の早帰りは持ち帰った分だけを得る。空帰り、中断、死亡、直接finishを呼んだだけの結果では帰還報酬を付けない。

`huntProgression` は既存v2プロフィールに付加するアプリ固有のv1拡張。既存特能、転生史、訪問台帳は保持する。拡張がない旧保存にはデフォルトを読み出すだけで、壊れた拡張は初期化・上書きしない。元のProfileStoreのvisit状態変更と追加報酬は同じchange/write内で確定する。再精算は元のentered判定で排除する。メニュー離脱はabandonedにする。

## 表示と入力

移動、自動戦闘、停止捕食、停止帰還を維持し、通常狩りの操作ボタンは増やさない。目標・達成数・持ち帰れる額の所有者をHuntFlowUiに一本化し、複数のガイドによる上書きを止める。操作短文は3.2秒で消える。旧first-hunt-guideは非表示、詳しい説明は任意で開く。結果画面で確保/損失、保有額、強化の具体差分、次の行動を示す。
