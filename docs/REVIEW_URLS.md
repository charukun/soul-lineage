# Canonical review URLs

Public RINNE review surfaces use extensionless URLs only.

- `/review-motion`
- `/review-assets`
- `/review-objects`
- `/review-effects`
- `/review-sound`
- `/review-battle`

The `.html` files with matching names are Vite build inputs, not alternate public routes. Do not link to them, use them for browser evidence, or diagnose public behavior from them.
