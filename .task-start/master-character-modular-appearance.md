# MasterCharacter modular appearance

Started 2026-09-12. Extend Sendagaya_Shino into a reusable visual-variation base that can produce clearly distinct NPC appearances while preserving the existing humanoid animation/collision contract. Target slots: face/head proportions, hair, body silhouette, outfit silhouette/palette and accessories. Existing game rules, saves, network authority, main/Production and parallel motion work are out of scope. Delivery ends at affected fast/browser verification and Ready for review; Integration owns develop merge and DEV publication.
