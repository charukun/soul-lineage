The lightweight generated catalog records the exact upstream clip name/index, source path, revision, original file Git blob SHA, SHA256, normalized channel fingerprint, author and license for every admitted canonical motion. Generation reads real pinned files; advertised pack totals are not used as clip counts. Standard and complete-tier packs are not conflated.

Modern dance, phone/driving/handgun actions, static bind poses, experimental skeleton disassembly, duplicate model embeddings, loop/partial/root-motion variants and failed target-rig samples are excluded or grouped explicitly. Unmodified legacy embedded variants remain selectable without increasing the canonical count. See the source-motion-evidence.json Actions artifact for the reproducible inventory and individual reasons.
