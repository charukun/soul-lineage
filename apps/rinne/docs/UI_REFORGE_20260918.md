# 輪廻転焦 操作・情報UI再鋳造 2026-09-18

最新 `develop` と本編仕様を正本に、プレイ中の操作系UI・情報系UIを、既存ゲームロジックを変えずに全面刷新する。

## 設計原則

- 中央の3D世界を主役にし、常時表示は「生命」「人生」「次の目的」「手元操作」へ絞る。
- フラットなWebカード、Glassmorphism、同寸ボタン列を使わない。羊皮紙、革、古金属、刻印、布、石の層で一つの世界観へ統一する。
- 操作は現行の移動・長押し休息・近接自動行動・敵接近自動戦闘を正本にし、不要な攻撃/生活/出航ボタンを増やさない。
- 状態差は色だけでなく、輪郭、切欠き、紋章、発光、沈み込み、素材差、動きで示す。
- 縦持ちとPixel Fold級画面を優先し、safe area内で44px以上の主要タップ面積を確保する。

## HUD構造

### 命脈環
画面左上に世代・年齢・命・息を一体化した小型の紋章HUDを置く。命/息は金属槽と液体層として表示し、数値の羅列ではなく危険度を一目で読める構成にする。

### 導き札
画面上部中央は羊皮紙の細い導き札とし、章/段階、短い目的、方角/距離を同じguidance targetから表示する。救助時は残秒を主情報へ昇格する。

### 戦闘相
戦闘時だけ中央上寄りに `序 / 破 / 急` を表示する。三段を独立カードにせず、一つの刃/紋章状レールの現在段として扱う。非戦闘時は消す。

### 手元操作
下部は `心 / 技 / 体 / 装` の4入口を基本とし、世界側の必須操作と競合しない低い帯に配置する。地図は下部から外し、画面右上の常設マップレーダーから詳細地図を開く。人生/系譜は左上プレイヤー情報の `記` から開く。出生時など実際に任意会話が可能な場面だけ中央寄りへ `話す` を一時出現させる。

## 情報画面

- 心、技、体、装、地図、記録、転生は同じ「古い旅装具を開く」画面体系へ統一する。心/技/体/装は上段1行3列の選択スロット + 下段5列グリッドを共通骨格とする。
- メニュー枠は上枠/留め具/内側面材/下部固定操作を持ち、角丸カードの集合にしない。
- 長い一覧はスクロール前提にせず、既存仕様どおりタブとページ送りで到達させる。
- 閉じる、戻る、決定、前後ページを固定位置へ置く。
- 転生は「生涯記録 → 残るもの/手放すもの → 出生先 → 最終決定」の不可逆確認を視覚的に明確化する。

## 状態表現

- 村: 蜂蜜色、革色、空色。
- 前線: 灰紫、錆赤、琥珀。
- 凱旋: 淡金。
- 輪廻: 白、淡藤。
- 危険状態だけ強い朱を使い、通常画面を常時赤くしない。
- 通知はWebトーストではなく、画面端から短時間だけ現れる刻印銘板として表示する。
- 会話は吹き出しではなく、話者の気配と文を一体化した布/羊皮紙の会話帯として表示する。

## 非変更契約

- 年齢、人生時計、保存、戦闘、装備、MURA座標、guidance target、Tidebreak入力/自動戦闘の意味を変更しない。
- DEBUG専用時間操作を通常操作として昇格させない。
- UIからゲームstateを直接書き換えず、既存command/adapterを使う。
- 他appの直接importを追加しない。

## 検証

- 360x640、390x844、844x390で主要HUD/メニューがsafe area内に収まる。
- 出生中だけ任意会話操作が出現し、通常生活で不要なcontext buttonが常駐しない。
- 戦闘中だけ序破急が現れる。
- 心/技/体/装、レーダーから開く地図、記録を開閉した後にゲーム入力が復帰する。
- 既存の局所テストとRinne buildを壊さない。
