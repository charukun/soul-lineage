# 100年生 タイトル画面

## 目的

`apps/rinne` の入口をWebアプリ風のカードUIから、背景世界を主役にしたコンシューマ向けゲームのタイトル画面へ置き換える。

## 正式表記

- 作品タイトル: `100年生`
- サブタイトル: `輪廻転焦`
- コピー: `暮らし、戦い、遺し、また生まれる。`

## 受入基準

- 青夜景を基調とした壮大な世界景観を画面全体で見せ、タイトルとメニューはその上に重ねる。
- 世界樹と月を核にした金色の紋章をタイトル上部へ配置する。
- メイン導線は `新しい人生`。`つづきから` を主導線にしない。
- タイトル画面の常設メニューは `新しい人生` / `旅の記録` / `村へ参加` / `設定` の文字メニューに絞る。
- 4項目の文字メニューは同じ無枠の視覚契約を共有し、`村へ参加` だけ旧UI由来の背景色・カード・枠を残さない。
- 角丸カード、入力フォーム、説明文付き大型ボタンをタイトル画面の主UIとして使わない。
- `旅の記録` は既存セーブがある場合に現在の人生へ戻る入口を含める。セーブがない場合も画面構成を変えず、利用不可状態を文字と選択状態で示す。
- キーボード、タッチ、ゲームパッド相当のフォーカスを想定し、選択状態は色だけでなくポインタ・下線・発光を併用する。
- 背景は雲、霧、光、星、遠景灯火などの緩やかなレイヤー演出で生命感を出す。`prefers-reduced-motion` では演出を止めても情報と操作を失わない。
- スマートフォン縦横とデスクトップ横長の双方で、タイトル、主要メニュー、選択中項目が安全領域から外れない。
- 既存の新規人生、既存セーブ再開、村参加の機能契約は維持する。
- `新しい人生` の置換確認は、薄い矩形カードと均一な枠線だけで成立させず、輪廻転焦固有の額縁、面材、内外の陰影、装飾、決定状態の奥行きを持つコンシューマゲーム向け確認画面として表現する。
- 同じ表現原則をタイトル周辺の主要ダイアログ/メニューへ水平展開し、設定、村参加、人生終端などでWebアプリ風のフラットカードが再導入されないようにする。ただし各画面の情報量と役割に合わせて密度を調整し、同じカードの複製にはしない。
- 縦持ちでは主要決定を先に読める一列構成、横持ち/デスクトップでは視線移動が短い横並びまたは広幅構成を使い、どちらもタッチ領域とフォーカス可視性を維持する。

## 世界生成ロード画面

- タイトルから本編へ移るロード中は、完成画像を画面へ貼り付けた疑似ゲーム画面にしない。文字を焼き込んだ全画面スクリーンショットや分割画像をロードUIの正本として使わない。
- 背景は実際の `#game` WebGL キャンバスをそのまま生かし、世界レンダラーが準備できるまでは CSS の空・霧・光・世界儀モチーフだけを軽量なフォールバックとして重ねる。レンダラーが最初のプレビューを描いた後は、その実フレームがロード画面の世界として読めること。
- 主見出し `世界をつくっています`、現在工程、工程進捗、失敗理由、再試行は実DOMで表示する。画像内へ文字を焼き込まない。`aria-live` の通知契約も同じ実DOMを使う。
- 進捗は実際の起動工程から更新し、時間経過だけで増える擬似パーセントを作らない。少なくとも runtime 読み込み、村レイアウト、世界レンダラー、初期プレビューの区切りをユーザーへ示す。
- 起動失敗時は理由を表示し、`もう一度` で再試行できる状態を維持する。正常ロード時の見た目と失敗UIの操作性を分離する。
- スマートフォン縦持ちでは中央の工程表示と世界の見通しを両立し、横持ち/デスクトップでも実キャンバスを不必要に覆わない。
- ロード画面のために重いリアルタイム blur / backdrop-filter / 追加WebGL後処理を導入しない。既存レンダラーの準備を阻害せず、CSS演出は低負荷かつ `prefers-reduced-motion` で停止できること。

## 実装境界

タイトル画面の見た目と入口整理は `apps/rinne` 内で完結させる。ゲーム本編、保存schema、共有world、他appの表示契約は変更しない。
