# 輪廻転焦 Gameplay upgrade 2026-09-16

この変更は、輪廻転焦本編の移動・休息・戦闘・装備・HUD・村表現・音を一段引き上げ、既存の村アプリおよび尽喰廻遊と共有できるゲーム機能はapp間直接importではなく共有packageへ寄せる。

## 受入条件

- 通常移動速度を現状より明確に上げる。ダッシュを追加し、通常移動より大きいスタミナ消費を持たせる。
- 長押し中は休憩状態へ入り、休憩モーションとスタミナ回復を同時に行う。移動・戦闘入力で自然に解除する。
- 建物は現行の簡易表現を主経路にせず、尽喰廻遊で使用しているレビュー済み環境asset系統を共有asset/package経由で輪廻転焦と村アプリへ適用する。
- 建物・施設まわりの移動collisionを見直し、見た目より過大な当たり判定や通行可能に見える隙間を塞ぐ不可視collisionを除去する。角や壁面での引っ掛かりを軽減する。
- 村に複数のかかしを配置し、近接時は敵遭遇と同じ戦闘態勢へ遷移する。戦闘状態機械・対象選択・戦闘HUDの共通化は尽喰廻遊と共有package契約で行う。
- 画面下部へ「意識」「所持品」を追加し、意識バランス・装備/所持品を設定できるゲーム内UIへ接続する。
- 武器持ち替えは施設での受取と冒険中の拾得の両方から所持品へ入り、選択して装備変更できる。
- 村の防具屋等へ防具立てを配置し、近接操作で防具一式を着替えられる。
- マップUIを追加し、現在位置と主要施設の位置関係を把握できるようにする。
- プレイヤー情報HUDをゲーム画面中心のコンシューマ向け表現へ整理し、HP/スタミナ/状態/装備等の優先情報を読み取りやすくする。
- 時間経過を早める操作はデバッグ専用として下部コントロールへ隔離し、通常進行機能として扱わない。
- タイトルの「新しい人生」後に挟まる不要な中間画面を廃止し、そのままプレイ開始へ遷移する。
- 会話表示は村アプリ由来の共有会話機構を利用し、輪廻転焦独自の重複実装を増やさない。
- 無音状態を解消し、最低限、移動/環境/戦闘/取得・装備/UIに音声フィードバックを入れる。既存の共有audio資産・契約を優先する。
- スマートフォン縦画面で開く主要パネルは、visual viewport と safe area の内側へ必ず収める。右端や上端へ閉じる操作を逃がさず、本文が長い場合はパネル内スクロールへ切り替え、横方向の画面外はみ出しを発生させない。
- 3個以上の候補から選ぶUIは、スマートフォンを含めて縦1列へ退化させず、最低3列のグリッドで同時比較できるようにする。タイトルメニュー、Reviewナビ、人生終了時など同種の選択肢へ同じ原則を適用し、2択の確認ダイアログは対象外とする。

## 境界

- `apps/rinne` / `apps/village` / `apps/demon` は互いを直接importしない。
- 共通化は `packages/*` の明示的workspace依存として実装する。
- 既存の年齢、意識バランス、序破急、スタミナ、装備、出生進行の意味を変更しない。
- main / Production は変更しない。DEV向け通常Integrationへ引き渡す。
