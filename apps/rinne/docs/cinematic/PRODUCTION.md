# 百年転生 — 六秒で村を飛び、次の命へ
## 採用メディア
OPは6.000秒 / 144フレーム。Veo 3.1 Fastによる一括生成は、母が主人公へ変形し、等身が崩れ、奥行きも弱かったため不採用。ユーザーの修正を受け、人物ごとの専用キーフレームを新規作成し、Google Flow **Omni 1.1 Flash**で4秒の独立ショットを4本生成した。モデル名は実際のFlow UI表示による。Veo生成物を納品映画と称さない。

6秒の編集は実際の人物・環境・カメラの動きを切り出したもの。静止画ズーム、再生速度変更、人物のモーフィングで時代をつながない。村の屋根・木・路地を通る移動と、最後の大きな上昇で奥行きと高度差を出す。

- 生成元: 1280×720。Web版: 1920×1080 / 24fps / H.264 / faststart / 約4.70 MiB。1080pは拡大出力であり、ネイティブ1080p生成ではない。
- 6秒で最後の村構図を保持し、ロゴ→メニューを重ねる。Living Stillループは今回採用しない。未検証のループを作らず、同じデコード済み最終フレームに着地する。
- 生成サービス内蔵音声のみ。初回自動再生はmuted。外部音楽・素材の無断転用なし。購入・追加課金なし。
- ユーザーの「いいよ」を受けて画像使用権の同意を実行した。旧版の同意待ち記述は履歴であり、現在の阻害要因ではない。

## ゲームとの接続
実モデルは `protagonist.villager.v1`。象牙色の短い幾何学的な髪、黒い楕円の目、クリームの巻き衣、オリーブのズボン、茶のブーツ。**旧プロンプトの「約3頭身」は誤差を招いたため廃止。実モデル画像を優先し、短い胴・脚と大きな頭、およそ2.2頭身を固定した。** 母は茶髪とオリーブのフードで別人物として固定。

母との幼少期→青年の武具・戦闘→武器を置く老年→次世代の新生児、という順序。装備や戦闘力を新生児へ引き継がせない。故郷と系譜が続くことを、同じ村と世代の対置で表す。

老年の明示的な死の生成はサービス側で拒否された。採用版は安全な別場面「引退した老人が村を眺めて休む」。死の直接描写が完成したとは扱わない。6秒では説明字幕を入れず、老年→新生児の編集で人生の継続を示唆する。

## 評価と限界
- 確認済み: 母が青年へ変化しない、青年の顔と短い四肢、実際の足・腕・剣の動き、屋根・木の前景とパララックス、最後の高度差、明るい村。
- 編集除外: 初回Veo全体、ショット01冒頭の構図ジャンプ、各クリップ後半の不要な長さ。
- 限界: 世代の説明は6秒のモンタージュ。死の直接描写は含まない。遠景の建物や村の地理は映画美術の解釈。環境の生成差異と細部のAI誤差は残る。商用リリースの最終アート承認を自動認定しない。
- 全画面と縦画面を確認。portraitは50%固定クロップで、途中のCSSパンは行わない。
- posterは採用MP4の最終表示フレームから抽出。別の世界へ切り替えない。

## 実装・検証・差し替え
`public/title-assets/cinematic/manifest.json`がmovie/poster/revision/dimensions/fps/duration/title landing/skipの正本。初回1.8秒、再訪即skip、本編から帰還はOPなし。再生中メニュー非表示・inert。失敗・reduce motionはposter。

次回は承認済みMP4に対して `scripts/import-title-movie.mjs --input ... --revision ... --provider ...` を実行する。ループが実際に成立すると確認した8秒マスターのみ `--loop`。MP4・poster・manifest・provenanceの交換で再生コードを変更しない。

`title-cinematic-browser.test.mjs`は今回の配信MP4そのものをデコードし、4場面のportraitとタイトルportrait/landscapeを撮影する。合成H.264 fixtureはskip/障害等の独立した境界条件に限定し、配信映像の証拠と分ける。exact-headのActions jobに `RINNE_TITLE_IMAGE` と `RINNE_BROWSER_EVIDENCE` を記録する。
