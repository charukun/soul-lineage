# 心技体 UI 統一 2026-09-17

## 目的

プレイ画面下部の `心 / 技 / 体` を、同一の木・真鍮・羊皮紙ベースのゲームUIへ統一し、スマホで一覧性と操作性を上げる。あわせて起動画面を静的な背景画像依存から、本編WebGL世界を使うゲーム内タイトル演出へ引き上げる。

## 受入条件

- タイトルは `心` / `技` / `体` の1文字だけにする。
- 下部ナビは `心 / 技 / 体 / 具 / 時` の5項目に統一し、走・図を置かない。
- 心はセット状態を持たず、会得済み心得を5列グリッドで表示する。詳細は長押しポップアップで確認する。
- 心得の効果は会得時点で有効とし、心画面のON/OFFで効果を切り替えない。
- 技は序破急を内包する「1つの技」を閃きで会得する。3つの意識スロットへ会得済み技をセットする。
- 技一覧は5列グリッドとし、各技は名前とアイコンを主表示、長押しで詳細を確認する。
- 体は上段に `構え / 間合い / 残心` の3スロットを並べ、会得済み候補からセットする。
- 体一覧は5列グリッド、`全て / 構え / 間合い / 残心` フィルタ付き。各カードに属性バッジを付ける。
- 心技体でタイトル板、セクション見出し、スロット、グリッドカード、長押し詳細、下部ナビの形状・余白・素材感を共通化する。
- フラットデザイン / Glassmorphism は使用しない。
- 390x844級の縦画面で5列グリッドとタップ領域が成立する。
- 既存保存データは自動移行し、旧 `combatLoadout` / `skillWeights` を破壊しない。
- 起動画面は準備済み本編WebGLキャンバスを専用title canvasへミラーし、既存world画像は取得失敗時だけのフォールバックにする。
- 起動画面は光・霧・粒子・視差・カメラドリフトを重ね、メニューもプレイ画面と同じ木・真鍮系ゲームUIへ統一する。
- 起動画面のライブ背景処理は本編DOMを可視化せず、既存のhidden/操作/ブラウザテスト契約を壊さない。
