# RINNE UI 5 direction

UI 5 is an interaction-model reset, not a reskin.

## Research references

- Infinity Nikki: official update notes describe grouping secondary functions into a Function Hub, adding an Immersive Mode, and reducing/repositioning mobile action buttons as the main interface grew.
- Animal Crossing: New Horizons: day-to-day systems are collected into the NookPhone while the island itself stays the primary play surface.
- Sky: Children of the Light: atmosphere and avatar motion dominate the exploration view; persistent HUD is deliberately sparse.
- Genshin Impact mobile: action affordances sit near screen edges while the 3D world remains readable.

These are reference principles only. Do not copy proprietary assets, layouts, icon sets, typography, or trade dress.

## RINNE translation

1. Exploration shows at most one persistent function-hub control plus contextual actions.
2. Heart, techniques, body, items, map, and record live behind the hub.
3. Dialogue suppresses nonessential HUD until the line is dismissed.
4. Full journals fully own the viewport. Never leave a half-height empty archive slab over gameplay.
5. Family resume screens show the current life and resume action before optional history.
6. Cute fantasy is primary: cream paper, soft wood, peach, sky blue, mint, honey, rounded stitched forms, small botanical motifs.
7. The title screen remains the approved visual anchor.
8. Every shipped UI revision increments the visible RINNE UI version.
