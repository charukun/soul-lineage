# 風待ちの里 — 人生を巡る体験マップ

## Revision 4

出生村は、既存施設の寄せ集めではなく「暮らしている村」として地区を分ける。人生・戦闘・閃き・装備のルールは変えず、既存MURA施設と既存アセットを使って選択肢と景観密度を増やす。

### 追加された既存施設

料亭、酒場、防具屋、装飾工房、道具屋、家具屋、資材置き場、泥採集場、猟場、釣り堀、住宅2棟を出生村へ追加する。屋内を持つ施設には既存の家具種だけで室内を構成し、屋外施設へ偽の室内を作らない。

既存の経験種別だけを使い、料亭の観察、酒場の呼吸、家具の手伝い、道具・防具の手入れ、細工への集中、資材整理、湿地への適応、猟場の追跡、水辺の姿勢調整を追加する。新しい報酬・レベル・クエストは導入しない。

### 見た目

既存の `@soul/housing-assets` を活用し、農園は風車、木工所は木漏れ日の家系、市場は天幕付き市場、防具屋は星見の家系、道具屋は森のまるい家系へ寄せる。施設のゲーム上のkind、footprint、collision、interior authorityはMURA側を維持する。

庭には既存の花、街灯、魔除け灯、丸太の卓、ベンチを追加し、施設間の余白にも用途を持たせる。

## 道と互換性

母の村巡りと目的地案内は従来の生活圏ループを維持しつつ、西側の外周路と東側の職人工房・水辺への枝を追加する。港は既存の東海岸座標を維持し、川は共有地形の既存渡しだけを使う。

`rinne-windward-birth-v1` の未編集 revision 2 / revision 3 だけを revision 4 へ移行する。既存ID・家具・一族/セーブのidentityを維持し、共有コード付き村、独自編集済み外観、別村は置換しない。
