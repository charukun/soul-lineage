# 風待ちの里 — 人生を巡る体験マップ

## 目的と範囲

既定の出生村を「施設の一覧」から、暮らし・修行・冒険・帰還がつながる村へ再配置する。人生、戦闘、閃き、装備、入力、共有村の経済を別ルールへ置き換えない。

## 空間と体験の対応

| 場所 | 体験する既存仕様 | 配置の狙い |
| --- | --- | --- |
| 一族の家と集いの広場 | 母の抱っこ、4歳の自立、遊び、手伝い、家具を使う暮らし | 生まれる場所と帰れる場所を隣接させる |
| 家並み、市場、宿、学びと祈りの庭 | 観察、呼吸、姿勢、学び、読書、集中、祈り、気配 | 入口から離れた屋外活動と室内家具を選んで体験できる |
| 森、木工の庭、畑、果樹園 | 足跡、手入れ、手伝い、環境への適応 | 生活と身法・心得の経験を結ぶ寄り道 |
| 鍛冶の通りと稽古の庭 | 鍛冶見学、7歳からの武具、稽古見学、間合い、反復、受身、かかしへの打ち込み | 武具・見学・実際の打ち込みを別の場所として配置する |
| 南の見張りと村外 | 実戦、序破急、意識・編成の結果、消耗、負傷や死亡 | 通常の生活道路から分岐して危険へ近づく |
| 二つの渡しと船着き場 | 休息、船上の祈り、15歳以降の出航、既存の前線・拾得・帰還 | 正規の渡しを経由し、果樹園側にも帰路を持つ |
| 帰った里と人生の記録 | 凱旋、一族の故郷、寿命・死、系譜、次の出生 | 転生は既存の人生終了経路。訪問だけで転生する施設は追加しない |

これにより既存の22経験種別を、屋内外の活動地点、かかし、港、既存戦闘へ対応付ける。新規クエスト報酬、資源採取システム、強制順路、レベル上げ施設は追加しない。休み場・看護の庭を、未実装の即時全回復サービスと扱わない。

## 道と読みやすさ

- 家・広場・学校・教会・鍛冶・道場・看護を生活圏のループで結び、木立と畑への小径を分岐させる。
- 道場の見学点をかかし群から離す。母の村巡りと通常案内は打ち込み区画を通り抜けない。
- 港は既存の東海岸の座標を維持する。南の渡し（z=-42）と北の渡し（z=54）は共有地形の `riverX` / `inWater` を使う。川の任意の地点に橋を捏造しない。
- 腰掛け、灯り、花を体験地点と休み場に配置する。道路グラフは村巡りと目的地案内に使用する。専用の道路描画・木製道標はこの変更には含まれず、地面の小径は既存描画のままとする。
- 目的地案内と母の村巡りは同じ道路グラフを参照する。元の到着条件・母の台詞・人生の目標選択は維持し、曲がり角だけを中継目標にする。
- 帰還や旧セーブが建物内座標から再開した際の案内は、その建物の実際の入口へ向ける。衝突判定や移動許可を案内側で書き換えない。

## 所有境界と互換性

`rinne-windward-birth-v1` の未編集 revision 2 外観だけを revision 3 へ更新する。既存37オブジェクトのID、室内家具、村IDを維持する。共有コード付き・編集された外観・別村は置換せず、既存の配置経路を使う。

RINNE専用の配置・案内は `village-journey*.js` に閉じ、共有MURA地形・カタログを正本として参照する。広場、武具、かかし、出生、前線、系譜の既存IDとライフサイクルは維持する。市場・作業ヤードなど、共有契約上室内を持たない施設には偽の入室地点を生成しない。

## 今回の検証範囲

Routine Fast DEVの変更JS構文・最終ソース整合性を対象とする。ブラウザ実プレイ、描画品質、FPS、通行の全経路、死亡から転生までの実行確認を、この変更の検証済み結果として主張しない。
