# 百年転生 スマホ技セットUI 2026-09-17

最新 `develop` を正本に、プレイ中に閃いた技をスマートフォンで素早く `序 / 破 / 急` へセットできるUIを追加する。

## 受入条件

- プレイ画面下部へ世界観に沿った `技` 操作を追加し、既存のダッシュ・意識・所持品・地図・DEBUGと同じゲームHUD内で扱う。
- 新しい技を閃いた直後は、プレイを大きく遮らない小型の `閃き` 通知を出し、`今セット` から技セットUIを直接開ける。
- 技セットはスマホ片手操作を優先し、基本操作を `技を選ぶ -> 序/破/急を選ぶ` の2タップで完了させる。ドラッグ必須にしない。
- 技セットUIは画面下から開く兵法帖/巻物風の半画面パネルとし、フラットデザイン・Glassmorphism・汎用Webカードへ戻さない。
- 技一覧には技名、種別、新着状態、現在のセット先、効果の短い要約を表示する。既存 `knownSkills` と `skillWeights` を正本にし、新しい技体系を作らない。
- `序 / 破 / 急` は大きな押下領域を持つ印章/札として表示し、選択中の技をどこへセットするか視覚的に明確にする。
- 閃き通知を閉じても、`技` 操作から既知の技をいつでも再設定できる。
- パネルは閉じるボタンに加えて、ヘッダーを下方向へスワイプして閉じられる。ゲーム移動入力と競合しない。
- 既存の技発見条件、support/action効果、戦闘の `序 / 破 / 急` 遷移、保存形式は変更しない。
- Pixel Fold級の縦画面、狭幅スマホ、safe area、reduced-motionを維持する。

## 境界

- `apps/rinne` 内の表示/入力拡張として実装し、他appを直接importしない。
- `knownSkills` 追加時の差分をプレイUI側で検知し、Domainの発見ロジックをUI都合で変更しない。
- main / Production は変更しない。
