# Arcanist Atlas Study

`arcanist.atlas-study.v1` is the runtime-procedural Arcanist comparison model requested for Visual Review Lab. It is preserved as a separate review artifact after the generic procedural reference catalog was retired.

The Lab must keep three concepts distinct:

- audited/real character assets and Motion Library models;
- this explicit `ARCANIST_ATLAS_STUDY / BLOCKOUT` comparison;
- the separate Blender DCC candidate being produced as `arcanist.atlas-dcc.v1`.

The Atlas study uses the audited humanoid source only as a rig/motion carrier, hides its render meshes for this explicit comparison, and mounts the Arcanist reference body plus the added hair, eyewear, mantle, robe, scroll/satchel, staff and book detail. It remains `runtime-procedural`, `BLOCKOUT`, and `productionReady=false`.

It must never be presented as PRIMARY, polished final art, a gameplay equipment grant, or a replacement for the DCC candidate. The generic reference-model picker stays retired; only this named user-requested study is exposed.
