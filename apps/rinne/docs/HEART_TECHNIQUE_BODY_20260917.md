# 輪廻転焦 心・技・体ロードアウト 2026-09-17

プレイ画面下部の戦闘設定を `心 / 技 / 体` に再編し、会得した要素をそれぞれのページで確認・セットできるようにする。

## 受入条件

- 下部HUDに `心 / 技 / 体` を独立した主要操作として配置し、`装` と合わせた4入口にする。既存の意識1画面へまとめない。
- `心` は上段3枠へ戦闘に持ち込む心得を配置し、下段へ会得済み心得を5列グリッドで一覧表示する。既存support skillを正本とする。
- `技` は上段の `序 / 破 / 急` 3枠を1組のコンボとして扱う。複数のコンボセットを追加・切替でき、下段の会得済みaction skill 5列グリッドから各枠へ設定できる。
- 各コンボの序/破/急スロットに `得意技` タグを付けられる。自動戦闘では得意技タグ付きセットを優先候補として扱う。
- 戦闘態勢中だけ使える `ワンモーション` を1つセットでき、プレイ画面からタップ発動できる。通常コンボよりスタミナ消費と発動後の隙を大きくし、自動戦闘を主役に保つ。
- `体` は上段を `構え / 戦法 / 残心` の3枠とし、選択中の枠に対応する会得済み身体要素を下段5列グリッドからセットできる。
- 体設定は単なる表示ではなく、少なくとも間合い・接近/離脱傾向・攻撃後の硬直/回復挙動へ軽量に反映する。
- 既存の技発見条件、人生/保存、武器、防具、Tidebreak連携を壊さない。旧 `skillWeights` 保存データは読み替えて移行する。
- UIは羊皮紙・革・真鍮・紋章を基調とし、フラットデザインやGlassmorphismを使わない。
- Pixel Fold級縦画面で片手操作しやすいタップ領域を維持する。
- Browser-Playtestで `心 / 技 / 体` の主要3ページとワンモーション設定が確認できるエビデンスキャプチャを残す。

## 境界

- `apps/rinne` 内のdomain/combat/UIとして実装し、他appを直接importしない。
- main / Production は変更しない。
