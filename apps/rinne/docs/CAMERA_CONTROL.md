# 百年転生 / 序破急バトル 共通カメラ操作

通常プレイと序破急バトルビューは、`@soul/rendering/snap-camera-control` の同じカメラHUD/操作契約を使う。

- 左上には、ゲーム画面を隠さない小型のかわいいカメラアイコンだけを表示する。
- カメラ操作は必ずそのアイコン上で開始する。画面の他領域から始まったタッチ/ドラッグは、キャラ移動・戦闘など各画面本来の入力へ渡す。
- アイコンを左右へスワイプすると、注視対象の周囲を45度ずつ回転する。1回の横スワイプは1段階。
- アイコンを上へスワイプするとズームイン、下へスワイプするとズームアウトする。ズームはドラッグ中に連続反映する。
- 回転後のキャラ移動軸は、固定ワールド軸ではなく現在のカメラ向きを毎フレーム参照する。
- 百年転生のタイトル演出・室内一人称ではHUDを無効化する。屋外と前線では同じ選択角度/ズームを使う。
- 序破急バトルビューの自動構図・閃きシネマティックは保持する。通常戦闘構図へ戻るとユーザーが選んだ45度角とズームへ復帰する。
- HUDは最低44px相当の操作領域を持ち、見た目は丸いレンズと小さなランプを持つコンパクトなカメラとして描画する。

カメラの回転・ズームは表示契約であり、戦闘判定・移動許可・当たり判定・AIなどのゲームルールを所有しない。
