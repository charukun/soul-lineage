# 輪廻転焦 カメラ操作表示

公開DEVの実機確認を正本として、通常プレイ中のカメラ操作は「常時見える縦レールの上を、カムコーダー型のつまみが上下する」一体型UIとする。

- 左上には細い縦レールを常時表示する。開閉式の別パネルにはしない。
- レール上の現在位置を示すつまみそのものを、カムコーダー（動画カメラ）型アイコンにする。レール上部へ別のカムコーダーボタンを置かず、丸いつまみも併設しない。
- カムコーダーつまみを上下へドラッグすると通常カメラ位置が連続的に変化し、離した後も選択値を維持する。
- レールとカムコーダーつまみ以外の不透明な板・カード・パネル・説明文は表示しない。ゲーム画面を隠さない。
- 見た目のカムコーダーは小さく保ちつつ、操作領域は最低44px相当を確保する。native rangeはキーボード・スクリーンリーダー・入力値の契約として透明な入力レイヤーに使ってよい。
- 視覚表現をブラウザ固有の `input[type=range]` のthumb/trackへ依存せず、Android Chromeを含むタッチブラウザで同じ「縦レール＋移動するカムコーダー」が見えること。
- 戦闘中は戦闘専用カメラを優先し、手動入力だけ無効化する。縦レールとカムコーダーつまみは常時表示を維持し、必要なら抑えたopacityで非操作状態を示す。戦闘終了後は保持していた通常カメラ値へ復帰する。

## 遮蔽物とプレイヤー視認性

固定方向の通常カメラで、建物・大型オブジェクトなどがカメラとプレイヤーの間に入った場合は、プレイヤーを隠している遮蔽物だけを自動で半透明化する。

- 対象は屋外の環境オブジェクトとし、地面・水面・プレイヤー・敵・UIは透過対象にしない。
- カメラからプレイヤーへ向けた視線上にある遮蔽物だけを透過し、遮蔽が外れたら滑らかに元の不透明度へ戻す。
- 複数の遮蔽物が重なった場合も、プレイヤーまでの視線上にあるものをすべて処理する。
- 透過中も深度判定を維持し、プレイヤーの位置関係を読み取りやすくする。
- 通常の半透明描画が過剰な負荷や描画順破綻を起こさないよう、対象メッシュだけを限定して更新し、毎フレームの不要なmaterial生成を行わない。

## DEV確認

スマートフォン縦持ちで、左上に細い縦レールが常時見えること、丸いつまみや独立した上部ボタンではなくカムコーダー型アイコン自体がレール上の現在位置を示すこと、上下ドラッグでそのカムコーダーが追従しながらカメラ位置が連続的に変化することを確認する。

屋外で建物や大型オブジェクトの裏へ移動し、プレイヤーを隠した対象だけが滑らかに透過してプレイヤーが見えること、遮蔽から出ると元の表示へ戻ること、複数遮蔽物が重なっても視認性が維持されることを確認する。
