# 輪廻転焦 カメラ操作表示

公開DEVの実機確認で、カメラアイコン展開時の縦調整UIが黒い矩形として強く見え、レールとつまみが視認できない状態を確認した。通常プレイ中のカメラ操作は次を受入条件とする。

- 左上のカメラ操作は小さなカムコーダー（動画カメラ）アイコンを常時表示し、説明文を置かない。静止画カメラの外形へ戻さない。
- 見た目は小さくても44px相当のタップ領域を維持する。
- 展開時は背景の不透明な板・カード・パネルを表示しない。ゲーム画面を隠さない透明な操作領域とする。
- 調整状態は細い縦レールと、現在位置が一目で分かる丸いつまみを必ず自前描画する。ブラウザ固有の `input[type=range]` 外観だけに可読性を依存しない。
- レールはカムコーダーアイコン直下の短い範囲に収め、画面中央方向へ張り出さない。
- native rangeはキーボード・スクリーンリーダー・入力値の契約として残してよいが、視覚表現はAndroid Chromeを含むタッチブラウザで同じ意味が読めること。
- 戦闘中は既存どおり手動カメラUIを閉じ、戦闘専用カメラを優先する。戦闘終了後は通常カメラ値へ復帰する。

## DEV確認

スマートフォン縦持ちで、左上にカムコーダー型アイコンが常時見えていること、押した時に「黒い縦長矩形」に見えないこと、縦レールとつまみが背景上で明瞭に見えること、上下ドラッグでカメラ位置が連続的に変化することを確認する。
