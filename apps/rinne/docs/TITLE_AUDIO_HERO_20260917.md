# 輪廻転焦 タイトル・サウンド・主人公更新 2026-09-17

最新 `develop` を正本に、タイトル画面の導線整理、タイトル/ゲーム音声の起動改善、背景演出強化、既定主人公モデルの見た目方向合わせを行う。

## 受入条件

- タイトルから `KayKitで遊ぶ` を削除する。
- `村コード` と `村へ参加` の重複導線は `村コード` を残し、タイトル上の `村へ参加` を削除する。ゲーム内の協力プレイ入口は別機能として保持する。
- `新しい人生` を `最初から` に変更し、保存がある場合だけ `続きから` を有効表示する。旧 `旅の記録` 文言・タイトル導線は廃止する。
- モバイルの autoplay 制限下でも、最初のユーザー操作後にタイトルBGM/環境音を確実に開始し、選択移動・決定に短い効果音を付ける。ゲーム本編へ遷移した後も既存ゲーム音を引き継ぐ。
- 背景は単純な一枚絵の拡大縮小だけでなく、前景/中景の視差、光、霧、粒子、ゆっくりしたカメラドリフトを重ねる。`prefers-reduced-motion` と既存の背景演出設定を尊重する。
- 背景画像の右側主人公に近い、髪の見える若いファンタジー冒険者を外部公開資産から比較し、ライセンス・固定revision・既存rig/runtime互換を優先して既定主人公へ採用する。
- 採用モデルは app 直書きではなく `@soul/characters` の既存KayKit foundation契約から選ぶ。mutable URLをruntime依存にしない。

## モデル選定

公開資産比較では KayKit Adventurers の `Rogue` が、背景右側の「髪が見える若い冒険者・軽装・首元の布/ケープ」という大形状に最も近く、既存Repositoryにも固定revision・CC0・Rig_Mediumとして導入済みのため第一候補とする。見た目確認後に別候補へ戻せるよう、選択はfoundationのhero既定値だけを変更する。

## 境界

- `apps/rinne` から他appへ直接importしない。
- main / Production は変更しない。
- imported KayKitモデルの既存 Production stage / visual approval を勝手に昇格しない。
- 既存の保存データ、寿命、戦闘、装備、村連携契約を変更しない。
