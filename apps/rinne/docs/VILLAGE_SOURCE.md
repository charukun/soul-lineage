# 輪廻転焦 出生村と村コード接続

通常プレイの出生村と、MURAAAAAAA の共有村コード接続を分離する。

## 標準の出生村

- 村コード未入力の通常プレイでは、輪廻転焦が所有する発展済みの固定出生村を使う。
- 配置思想は旧「血脈の系譜」の中央広場・主街路・住宅・道場・鍛冶・学習・祈り・治療・衛兵・外周訓練場を再構成し、現行 `@soul/world/mura` の建物/家具契約と現行RINNEアセットで表現する。
- 旧Bloodlineのコード・保存・描画assetを移植せず、空間構成と施設役割だけを参照する。
- 標準出生村は本編側のゲーム進行に必要な施設、入室可能な建物、室内家具、かかし、村外skirmishへの導線を最初から満たす。
- RINNEの標準出生村をMURAAAAAAA側へ書き戻さない。

## 村コード接続

- MURAAAAAAA共有村を使うのは、プレイヤーが村コードを明示入力し、そのlayoutの解決に成功した場合だけとする。
- 村コード未入力・空・無効・読込失敗では標準出生村へフォールバックし、暗黙に端末のMURA共有状態へ同期しない。
- コード接続時は共有村layoutを正本として読み、建物配置・room内家具をRINNEの入室・家具由来閃きへ利用する。
- コード接続中もRINNEから共有村の建築進行・経済・配置を勝手に変更しない。
- 通常村とコード村は同じRINNEゲームシステム、移動、入室、閃き、かかし修行、装備、戦闘を共有する。

## 受入条件

1. 新規ゲームを村コードなしで開始すると、MURAAAAAAAの端末内村ではなくRINNE専用出生村になる。
2. 出生村は住宅、中央広場/井戸、道場、鍛冶、学校/図書、祈り、診療、衛兵拠点、外周訓練場を視覚・ゲーム上の両方で判別できる。
3. 建物への入室、室内家具由来の生活経験/閃き、かかし修行、村外skirmishが標準出生村で成立する。
4. 村コードが入力され、有効な共有layoutを解決できた時だけコード先のMURAAAAAAA村へ切り替わる。
5. 無効コードや共有村未取得時は壊れた空マップにせず標準出生村を継続する。
6. コード村のroom家具はRINNEの閃き材料として読めるが、RINNEから共有layoutへ配置を上書きしない。
7. `apps/rinne` から `apps/village` を直接importせず、必要な共有契約は `packages/world` / Platform port 境界を使う。
8. 既存の出生→生活→室内閃き→かかし→村外実戦→死亡/生還→輪廻ループを維持する。
