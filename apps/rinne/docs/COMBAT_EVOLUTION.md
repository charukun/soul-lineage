# 多対多戦闘・成長循環の最終拡張

この文書は PR #728 の Tidebreak 戦闘コアを前提に、その次段で実装する本編戦闘拡張の受入条件を定義する。UI は引き続きじんく廻遊側を正本とし、Tidebreak の presentation UI は持ち込まない。

## 実装範囲

- 武器の実軌道をワールド空間で評価し、1回の攻撃で複数対象へ接触できる。突き・射撃など貫通しない攻撃は最初の有効接触で止まる。
- 敗北・被弾・スタミナ枯渇・間合い負け・包囲などの戦闘経験を、次の成長候補・閃き確率へ反映する。危険をゲーム側が自動救済するのではなく、経験が次の対応力へつながる。
- HPとは別に部位負傷を持ち、腕・脚・頭・胴の負傷が、その戦闘中と帰村後の一定期間に攻撃、移動、判断、スタミナ等へ影響する。負傷は保存・復元可能にする。
- 敵集団は役割を分担できる。前衛、側面、後衛、撤退、援護などを位置と武器から選ぶが、同時攻撃数を人工的に制限しない。
- 敵はプレイヤーの技使用履歴を短期記憶し、同一パターンへの警戒、距離変更、受け、返しを強める。記憶は戦闘単位で有限に保持する。
- マルチでは正面受け、側背面攻撃、長柄・遠距離などが位置関係から自然に有利不利を生み、固定ロールや専属ターゲットを要求しない。
- 習得済み技は使用経験に応じて足運び、溜め、拍子、受けの構成が個体差を持つ。同じ技名でも人生ごとの型差が生まれ、血の系譜へ要素を残せる入口を用意する。
- 飛び道具は弾数・実弾道・遮蔽物・盾・身体接触を同じ戦闘空間で処理する。遠距離は高性能でも有限弾数により継戦能力を制約する。
- 地形は射線、武器の振り幅、間合い、高低差、退路へ影響する。壁・柵・狭所などを無視して攻撃判定が貫通しない。
- 戦闘の seed、入力、位置、意識、技、接触、HP/負傷差分を軽量ログとして記録し、決定論的に再実行できるデバッグリプレイ基盤を持つ。

## 非目標

- 多人数・包囲に対する自動怯み耐性、復帰無敵、同時攻撃人数制限、人数補正の救済は追加しない。
- PR #739 が担当する派手な戦闘エフェクト資産・presentation adapter は変更しない。
- main / Production、品質 gate、既存 UI 所有境界は変更しない。

## 受入条件

1. 横薙ぎ等が軌道上の複数敵へ当たり、非貫通攻撃は遮蔽物または最初の有効接触で止まる。
2. 包囲・背面被弾・スタミナ枯渇・間合い負け等が経験として蓄積され、対応する技能成長へ寄与する。
3. 部位負傷が攻撃・移動・判断へ実際に影響し、save/restoreで失われない。
4. 敵集団に役割分担と短期学習があり、同じ技だけの反復に対して戦い方が変化する。
5. マルチで位置取りと武器特性による自然な連携効果が出るが、参加権の専属化はしない。
6. 飛び道具と地形が同じworld-space contact contractを使う。
7. replay記録から同じseed・入力列で主要戦闘結果を再現できる。
8. 怯み救済は入れず、敗北は成長動機として残す。
