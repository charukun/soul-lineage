# 多対多戦闘・プレイヤー学習型の最終拡張

この文書は PR #728 の Tidebreak 戦闘コアを前提に、その次段で実装する本編戦闘拡張の受入条件を定義する。UI は引き続きじんく廻遊側を正本とし、Tidebreak の presentation UI は持ち込まない。

## 原則

戦闘で成長するのはゲーム内キャラクターの能力値・技・血統ではなく、実際に遊ぶプレイヤー自身の理解・判断・意識である。敗北、包囲、背面被弾、間合い負け等はプレイヤーが次の戦い方を考える材料にはなるが、ゲーム内の経験値、適応値、技能解放、技変異、恒久補正には変換しない。

村での生活・活動履歴も記録には残せるが、技能解放、能力値、技性能、戦闘判断の恒久補正には使用しない。既存の意識バランスはその時点の戦闘判断を表す状態として扱い、戦闘回数や敗北回数による恒久成長値にはしない。

## 実装範囲

- 武器の実軌道をワールド空間で評価し、1回の攻撃で複数対象へ接触できる。突き・射撃など貫通しない攻撃は最初の有効接触で止まる。
- HPとは別に部位負傷を持ち、腕・脚・頭・胴の負傷が、その戦闘中と帰村後の一定期間に攻撃、移動、判断、スタミナ等へ影響する。負傷は保存・復元可能にする。これは成長ではなく負傷状態である。
- 敵集団は役割を分担できる。前衛、側面、後衛、撤退、援護などを位置と武器から選ぶが、同時攻撃数を人工的に制限しない。
- 敵はプレイヤーの技使用履歴を戦闘中だけ短期記憶し、同一パターンへの警戒、距離変更、受け、返しを強める。戦闘終了後へ恒久学習を持ち越さない。
- マルチでは正面受け、側背面攻撃、長柄・遠距離などが位置関係から自然に有利不利を生み、固定ロールや専属ターゲットを要求しない。
- 飛び道具は弾数・実弾道・遮蔽物・盾・身体接触を同じ戦闘空間で処理する。遠距離は高性能でも有限弾数により継戦能力を制約する。
- 地形は射線、武器の振り幅、間合い、高低差、退路へ影響する。壁・柵・狭所などを無視して攻撃判定が貫通しない。
- 戦闘の seed、入力、位置、意識、技、接触、HP/負傷差分を軽量ログとして記録し、決定論的に再実行できるデバッグリプレイ基盤を持つ。replay はデバッグ用であり成長資源にしない。

## 禁止するゲーム内成長

- 敗北・被弾・包囲・息切れ・間合い負け等を経験値や技能成長へ変換しない。
- 村での活動回数・活動スコアを技能解放や戦闘能力の強化へ変換しない。
- 戦闘回数や命中回数で技の足運び、拍子、テンポ、溜め、威力、判断性能を恒久変化させない。
- 戦闘から新技・技能を自動解放しない。
- 戦闘習熟、技の型、敗北経験を血の系譜へ継承しない。
- replay、敵短期学習、部位負傷をプレイヤーキャラクターの恒久成長値へ転用しない。

## 非目標

- 多人数・包囲に対する自動怯み耐性、復帰無敵、同時攻撃人数制限、人数補正の救済は追加しない。
- PR #739 が担当する派手な戦闘エフェクト資産・presentation adapter は変更しない。
- main / Production、品質 gate、既存 UI 所有境界は変更しない。

## 受入条件

1. 横薙ぎ等が軌道上の複数敵へ当たり、非貫通攻撃は遮蔽物または最初の有効接触で止まる。
2. 敗北・被弾・包囲・息切れ・生活活動履歴等はゲーム内成長値・技能解放・技変異へ一切変換されない。
3. 部位負傷が攻撃・移動・判断へ実際に影響し、save/restoreで失われないが、回復後に恒久補正を残さない。
4. 敵集団に役割分担と戦闘内だけの短期学習があり、同じ技だけの反復に対して戦い方が変化する。
5. マルチで位置取りと武器特性による自然な連携効果が出るが、参加権の専属化はしない。
6. 飛び道具と地形が同じworld-space contact contractを使う。
7. replay記録から同じseed・入力列で主要戦闘結果を再現でき、replay自体は成長へ利用されない。
8. 怯み救済は入れず、敗北はプレイヤー自身が次の判断を学ぶ材料としてのみ残す。

Depends-On: none
