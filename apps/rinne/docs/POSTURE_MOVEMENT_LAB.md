# 構え・姿勢・移動の改善（2026-09-14）

対象は専用 Visual Review Lab / Draft PR #23。SHINO を中心に、既存の idle / walk / run VRMA と剣5技を改善する。新しい攻撃モーションIDは追加していない。

## 原因と変更

- 工房の構えは、IK後に腰・腕の角度だけを足した静止クリップだった。共有 `bakeStanding` で13種の構えと通常姿勢を生成し、呼吸・重心・膝・足裏・両腕を一緒に解く。
- 工房の「体 / 歩行」「体 / ダッシュ」「Tidebreak」「共有VRMA」は異なる表示経路だった。同じ共有ランタイムの歩行・走行ベイクへ接続し、読込途中で選んだ古いクリップも更新する。
- 速度2.4で歩行と走行を切り替えていた。1.8–3.2の範囲で連続混合し、歩幅と再生位相も連続化。低速時は構えへの寄せを先に始める。
- 抜刀中の左腕と、抜刀完了直前の右腕の伸展率を連続化。走行時の剣は肘を曲げて腰寄りに保持し、左腕は足運びに合わせて振る。
- 最新develop `efe3940` の PR #156 を確認し、解剖学に沿った肘の向きと `SWORD_FREE_GUARD` をこのLabの剣5技へ調整して取り込んだ。develop全体のmergeや既存14回の剣修正の巻き戻しは行っていない。

## 反復確認

前回の剣14回の記録は `SWORD_REFERENCE_ITERATIONS.md` に残る。今回の姿勢・移動は次の5回。回数は変更後の実モデル確認に基づき、テストを繰り返した回数ではない。

| 回 | 修正後の確認 | 判定・次の修正 |
| --- | --- | --- |
| 1 | 18秒、自然体→抜刀→歩行→走行→停止→既存2技→納刀を実モデルで書き出し | 肘の伸び切りを解消。肘の張り出しと左手の向きが不自然 |
| 2 | 正面・側面で肘の方向、自由手の位置、手首を確認 | 肩幅の外への張り出しを減らす。通常姿勢の腕は骨格長から再計算が必要 |
| 3 | 通常姿勢の腕、減速中の歩幅、停止姿勢を確認 | 腕の過伸展を解消。止まる直前の姿勢変化を抑制 |
| 4 | 通常姿勢＋13構えの全身一覧、移動中の剣の保持位置を確認 | 通常の手と腰の間隔を調整。走行中は剣を前へ傾け、肘を腰へ寄せる |
| 5 | 抜刀・納刀の端点、最終18秒の実モデル確認 | 左腕の上書きと、抜刀完了時の右腕の伸び率の段差を解消 |
