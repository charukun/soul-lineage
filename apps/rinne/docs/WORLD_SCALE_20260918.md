# 輪廻転焦: 人間基準の村スケール調整

2026-09-18 の実画面確認で、輪廻転焦の村にある建物が人物に対して過大に見える問題を受けた受入記録です。

今回の実装では、1 world unit = 1 metre の共通契約は維持したまま、MURA の建物寸法を成人約1.7mとの対比で再調整します。住宅・店舗・公共施設・防衛施設は用途に応じた人間スケールの床面積へ縮小し、村アプリと輪廻転焦で同じ寸法・衝突・入口・室内境界を使います。尽喰廻遊の metre 契約は維持し、別単位へ分岐させません。

輪廻転焦の初期村 `風待ちの里` は、縮小後の建物を単に既存座標へ置くのではなく、徒歩で回れる集落として再配置します。中心広場から生活施設へ短時間で届き、建物同士が不自然に離れず、外周の採集・農業・見張り施設だけを少し遠くへ置きます。港だけは海岸側の独立目的地として扱います。

受入条件:

- 一般住宅は概ね 6〜10m 級、主要公共建築でも概ね 9〜14m 級を基準にし、人物に対して模型的な巨大建築にならない。
- 一族の邸宅は一般住宅より大きいが、現状の 28×26m から人間が生活する建物として妥当な規模へ縮小する。
- 村アプリと輪廻転焦は `@soul/world/mura/catalog` を唯一の物理寸法正本として使う。
- 輪廻転焦の初期村は縮小後の寸法で建物同士が重ならず、中心部が徒歩圏に収まる。
- 既存のゲーム進行、施設コスト、定員、仕事枠、ネットワーク/save schema は変更しない。
