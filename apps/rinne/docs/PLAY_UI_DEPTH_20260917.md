# 百年転生 プレイ画面UI立体化 2026-09-17

最新 `develop` を正本に、プレイ画面HUDと操作UIをゲーム世界に馴染む立体的な意匠へ刷新する。

## 受入条件

- フラットデザインは禁止。単色矩形・均一な半透明カード・汎用Webパネルを主表現にしない。
- HP/スタミナ、世代/年齢、目的表示、会話、通知、下部操作、意識/所持品/地図パネルを、羊皮紙・革・金属・木・紋章の層構造で統一する。
- ボタンは輪郭、ベベル、内側陰影、押下沈み込み、選択時の発光/装飾で状態を示し、色だけへ依存しない。
- 常設HUDは画面を覆いすぎず、中央のゲーム映像を主役にする。スマートフォンのsafe areaと縦画面を優先する。
- HP/スタミナは平坦な横棒ではなく、金属枠と液体/発光層を持つゲージとして再構成する。
- プレイヤー情報はカード化せず、紋章/メダリオン + 年齢/世代 + 装備要約の一体フレームとして見せる。
- 目的表示は羊皮紙の小型クエスト札へ変更し、章/目的/補助情報に視覚階層を付ける。
- 下部操作は同寸のWebボタン列ではなく、中央操作を強調した装飾付きアクションスロットにする。デバッグ時間操作は通常操作より明確に弱い意匠にする。
- 意識/所持品/地図パネルは額縁・留め具・内側面材を持つゲームメニューとして表示し、角丸カードの集合にしない。
- 会話とトーストは既存ゲーム内情報を保持しつつ、吹き出し/銘板として立体化する。
- hover専用にしない。タッチ、キーボード、ゲームパッド相当フォーカスで同じ状態差が読めること。
- 既存のゲームロジック、入力、保存、戦闘、装備、マップ情報の意味は変更しない。UI層のみをブラッシュアップする。

## 境界

- 変更対象は原則 `apps/rinne` の表示層。
- 他appへの直接importは追加しない。
- main / Production は変更しない。
- タイトル画面は今回の主対象外。プレイ画面に限定する。
