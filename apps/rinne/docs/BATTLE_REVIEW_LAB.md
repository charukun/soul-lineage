# 実戦 Visual Review Lab

`apps/rinne/review-battle.html` は、実ゲームと同じ `RaidHost` / Tidebreak 戦闘状態を人間が短時間で比較確認するためのレビュー画面とする。

## 受入条件

- 戦闘ロジックをレビュー用に複製しない。`RaidHost` が返す同じ戦闘スナップショットを表示する。
- 序破急の現在値は Tidebreak actor snapshot の `slot` (`jo` / `ha` / `kyu`) を正本とし、疑似タイマーで再計算しない。
- 序破急の状態機構は共通とし、輪廻転焦と尽喰廻遊では見た目だけを切り替える。UIスキン切替で戦闘をリセットしない。
- **尽喰廻遊スキンの見た目の正本は尽喰廻遊本編で既に使っている中央下部HUD** とする。序・破・急の横並び、相手名、技名、敵HPの細いバーという構成を維持し、Review専用の赤黒い角切りカードへ置き換えない。
- 尽喰廻遊本編とReviewの尽喰廻遊スキンは、同じ `@soul/shared-ui/phase-panel` のDOM描画部品とCSSを使用する。似せた複製実装を作らない。
- 自動ループとカメラ追従は常時ONとし、ON/OFF切替を表示しない。
- モデル選択は「自プレイヤーモデル」1つだけとし、対戦相手モデルはレビュー既定値へ固定する。モデル差し替えで戦闘ロジック・HP・攻撃タイミングを変更しない。
- 独立した左右の体力カード・行動カードは表示しない。戦闘の読み取りは序破急UI内へ集約する。
- 一時停止と最初からの操作はReview用操作として残す。
- モバイル幅でも、戦闘キャンバス、序破急UI、主要操作が同時に確認できる。
- 公開 Visual Review bundle は `/` と `/review.html` のどちらからでも同じランチャーへ到達でき、戻る導線や既存URLから `review.html` を開いても 404 にしない。

この文書はレビュー画面と共通表示部品の受入条件を定義し、Tidebreakの戦闘仕様・タイミング・入力・進行そのものは変更しない。
