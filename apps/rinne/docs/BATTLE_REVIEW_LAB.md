# 実戦 Visual Review Lab

`apps/rinne/review-battle.html` は、実ゲームと同じ `RaidHost` / Tidebreak 戦闘状態を人間が短時間で比較確認するためのレビュー画面とする。

## 受入条件

- 戦闘ロジックをレビュー用に複製しない。`RaidHost` が返す同じ戦闘スナップショットを表示する。
- 序破急の現在値は Tidebreak actor snapshot の `slot` (`jo` / `ha` / `kyu`) を正本とし、疑似タイマーで再計算しない。
- 序破急の状態機構は共通とし、輪廻転焦と尽喰廻遊では見た目だけを切り替える。UIスキン切替で戦闘をリセットしない。
- レビューの尽喰廻遊スキンと尽喰廻遊本編は、同じ shared-ui の描画部品・CSSを使用する。レビュー専用の似たUIや本編側のコピー実装は作らない。
- 尽喰廻遊スキンは右下の赤黒い角切りパネルを正本とする。本編では実際の技名・敵名・敵HPをこのパネルへ渡し、従来の中央下部の序破急表示を重ねて残さない。
- レビューでは序破急パネルだけを戦闘表示として残し、独立した体力カード・行動カードを置かない。
- 自動ループは常時ONとし、切替操作を置かない。戦闘終了後は同じ条件で次の戦闘へ進む。
- カメラ追従は常時ONとし、切替操作を置かない。両者の中点と広がりを追い、戦闘中の接触を見失わない。
- モデル選択は自プレイヤーだけを対象とし、対戦相手はレビュー既定モデルに固定する。選択は表示モデルだけを差し替え、戦闘ロジック・HP・攻撃タイミングを変更しない。
- モバイル幅でも、戦闘キャンバス、序破急UI、主要操作が同時に確認できる。

この文書はレビュー画面と本編が共有する表示部品の受入条件を定義し、本編の戦闘仕様そのものを変更しない。
