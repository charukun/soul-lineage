# 輪廻転焦 本編 Gameplay Quality Bar

この文書は `apps/rinne` を「操作できる試作」から「繰り返し遊べるゲーム」へ引き上げるための受入基準を定義する。

## 今回の改善範囲

- 1画面内で現在の目的、危険、主要操作が理解できること。
- スマートフォン縦持ちを基準に、通常プレイ中の不要なページスクロールを発生させないこと。
- 移動、接近、戦闘、会話/取得、休息、成長の各行動に即時の視覚・音・状態フィードバックがあること。
- プレイヤーが「次に何をするか」を迷わず、短い探索 → 遭遇 → 結果 → 次の目標というループを継続できること。
- 失敗や消耗が起きても、原因と回復手段が画面上で理解でき、再開までの操作が短いこと。
- 既存の世界・年齢・スタミナ・意識バランス・序破急・装備/拾得等の仕様を壊さず、UI/ゲーム進行側で可読性と手触りを上げること。

## 複数戦闘の同時進行原則

複数戦闘は「1対1を敵ごとに順番再生する処理」ではなく、全戦闘者が同一時間軸上で継続的に間合い・角度・脅威を更新する一つの戦闘として成立させる。

- 複数の敵は、現在攻撃中の1体を除いて停止・待機するのではなく、それぞれが接近、測り、回り込み、攻撃機会の探索、踏み込み、離脱・立て直しを同時に継続する。
- 攻撃しない敵が存在する場合も、固定された順番待ちではなく、武器リーチ、攻撃可能角度、味方との干渉、相手の向き、現在の体勢、危険度から「今は入れない」と判断した結果であること。
- プレイヤーとNPCは単一ターゲットだけを基準に立ち位置を決めず、戦闘集団全体の重心、包囲リスク、退路、武器リーチを考慮して間合いを更新する。囲まれたまま棒立ちせず、敵同士を重ねる、外周へ抜ける、近い敵へ踏み込んで他の敵との距離を作る等の位置取りが発生すること。
- 味方同士の身体重なりや同一地点への殺到を避け、接近角度と占有空間を分散する。結果として複数人が同時に戦闘意思を持ちながらも、常時全員が同時攻撃する団子状態にはしない。
- 序破急は単一の敵へ固定されたコンボ列に限定しない。同一の序破急の途中で状況に応じて対象を切り替えられ、払いで一人を崩し、次の動作で別の敵へ斬り上げ、急で背後の脅威へ旋回する等の複数人向け連続動作を許容する。
- 攻撃対象の切替時に不自然な瞬間回転やワープを行わず、足運び、身体の向き、武器軌道、既存モーションの接続を通して次の間合いへ移る。
- 検証では、3体以上の敵が存在する状態で「1体ずつ停止して順番に戦う」挙動へ退行していないこと、非攻撃中の敵も位置・角度・脅威状態を更新し続けていること、複数の敵との距離が同時に変化することを確認する。

## 出生期の母との村巡り

- キャラクターの状態変化は、必要な瞬間だけ頭上へ短い文章が浮かび上がって流れ、自然に消える演出で伝えられること。出生直後は最初の状態として「抱っこされている…」を表示する。
- 0歳で始まると母が子の名前を呼び、「お外は初めてだね」と語りかける。出生期の説明を右上の目的地UIへ依存させず、母との会話と実際の村の景色から世界を理解できること。
- 0〜4歳の `birth` 中は、母が子を抱いたまま村の生活施設を自動で巡る。施設へ着くたび、母がその場所の用途・暮らし・世界観に結びついた短い台詞を話し、散策とチュートリアルを同じ体験にする。
- `birth` 中は母からの自発的な語りだけで進め、プレイヤー側の「話す」操作を表示しない。能動的な会話操作は自立後、実際に会話対象へ話しかけられる段階で初めて提示する。
- プレイヤーが移動入力をした間は母の移動を直接操作できる。入力を止めて少し経つと自動散策へ戻り、放置して眺めるだけでも4歳まで村巡りが続くこと。
- 散策速度は村の大きさに対して極端に遅くならないこと。巡回施設どうしの代表的な距離から速度を調整し、広い村では移動待ちが主役にならず、近距離では走り回るような速さにしない。手動操作は自動散策より少し速くする。
- 同じ共有村を扱う村アプリの生活者速度感を基準にし、母の自動散策は通常住民より軽快でも護衛の巡回速度を超えないこと。手動操作だけ入力応答のため小幅な上乗せを許容し、`apps/rinne` から `apps/village` を直接参照しない。
- `birth` 中の子ども自身は歩行状態にせず、母が移動主体であることを維持する。4歳の自立時に母の腕から地面へ降り、自力移動へ明瞭に切り替える。

## 一族と出生村の進行原則

輪廻転焦の恒久的な成長主体は個体能力ではなく、一族の記録とプレイヤー自身の知識である。世界は積み重なるが、新しい人生の身体能力や所有物は積み重ねない。

- 一族の最初の人生は、その時点で出生可能な村からランダムに選ばれた村で0歳から始まる。再現可能なゲーム状態では seed に基づいて選択してよい。
- 冒険へ出た人物が生きて出生村へ帰還したとき、その村を一族の「故郷」として解放する。帰還していない村を任意の再出生先として選べない。
- 次の人生では、解放済みの故郷を出生村として選ぶか、再び出生可能な村からランダムに出生する。
- 再出生は必ず0歳、基礎装備、基礎技、初期体力・スタミナ、未経験の状態から始める。前世の武器、防具、技、序破急の配分、経験値、能力値を引き継がない。
- 一族をまたいで保持してよいのは、生涯の記録、解放済み故郷、世界側に属する変化など、個体の強さではない情報だけとする。
- 村アプリを含む世界状態は個体セーブと同一視しない。出生村は portable な village ID で参照し、`apps/rinne` から他appへ直接依存しない。

この原則により、100代目でも出生時は赤子であり、周回そのものが攻撃力や装備を増幅しない。攻略上の優位は、過去の人生で得た地理・敵・経路・時間配分への理解と、帰還によって獲得した出生地の選択肢から生まれる。

## 最低品質ライン

1. **Playability**: 初見でも主要操作を30秒以内に把握でき、開始から最初の有意味な遭遇まで停滞しない。
2. **Readable state**: 体力/消耗/現在目標/相互作用可能状態/戦闘状態を常時または必要時に即認識できる。
3. **Core loop**: 探索 → 相互作用/戦闘 → 報酬または状態変化 → 次の目的、が画面遷移や説明文に埋もれない。
4. **Mobile fit**: 主要ゲームHUDと操作は1 viewport内に収まり、通常プレイにWebページ的スクロールを要求しない。
5. **Feedback**: 入力、命中、被弾、取得、休息、成長、目的更新に最低1つ以上の明瞭なフィードバックを持つ。
6. **Recovery**: 行動不能、消耗、敗北、誤操作からの復帰導線を見失わない。
7. **No regression**: `apps/rinne` の既存ゲーム仕様と共有package境界を維持し、他appへ直接依存しない。
