# 輪廻転焦 本編 Gameplay Quality Bar

この文書は `apps/rinne` を「操作できる試作」から「繰り返し遊べるゲーム」へ引き上げるための受入基準を定義する。

## 今回の改善範囲

- 1画面内で現在の目的、危険、主要操作が理解できること。
- スマートフォン縦持ちを基準に、通常プレイ中の不要なページスクロールを発生させないこと。
- 移動、接近、戦闘、会話/取得、休息、成長の各行動に即時の視覚・音・状態フィードバックがあること。
- プレイヤーが「次に何をするか」を迷わず、短い探索 → 遭遇 → 結果 → 次の目標というループを継続できること。
- 失敗や消耗が起きても、原因と回復手段が画面上で理解でき、再開までの操作が短いこと。
- 既存の世界・年齢・スタミナ・意識バランス・序破急・装備/拾得等の仕様を壊さず、UI/ゲーム進行側で可読性と手触りを上げること。

## 最低品質ライン

1. **Playability**: 初見でも主要操作を30秒以内に把握でき、開始から最初の有意味な遭遇まで停滞しない。
2. **Readable state**: 体力/消耗/現在目標/相互作用可能状態/戦闘状態を常時または必要時に即認識できる。
3. **Core loop**: 探索 → 相互作用/戦闘 → 報酬または状態変化 → 次の目的、が画面遷移や説明文に埋もれない。
4. **Mobile fit**: 主要ゲームHUDと操作は1 viewport内に収まり、通常プレイにWebページ的スクロールを要求しない。
5. **Feedback**: 入力、命中、被弾、取得、休息、成長、目的更新に最低1つ以上の明瞭なフィードバックを持つ。
6. **Recovery**: 行動不能、消耗、敗北、誤操作からの復帰導線を見失わない。
7. **No regression**: `apps/rinne` の既存ゲーム仕様と共有package境界を維持し、他appへ直接依存しない。

## 実装方針

今回のWORKでは、上記品質ラインを満たすために現行本編をレビューし、効果の大きい問題から修正する。巨大な新システムを追加するより、現行ループの操作性・可読性・フィードバック・テンポを優先する。
