# 尽喰廻遊: 襲撃先と捕食の表示契約

## 襲撃先の選択

襲撃先は固有の村名ではなく、村の規模と危険度を主情報として選ぶ。規模には実際の建物・住人数、危険度には実際の敵構成に対応する根拠を添える。獲得できる記憶は副情報として残す。表示だけを変更して全候補の規模を同一にしない。

生成村のID、入村履歴、一度入った村への再訪禁止、所有者・輸入村の識別契約は維持する。既存の保存済み候補を壊さずに扱い、読み込んだハウジングは実際の配置を改変しない。

## 捕食モーション

直立したまま顎だけを周期的に開閉する表現を、身を落とす、獲物へ手を伸ばす、引き寄せる、噛み込む、嚥下して姿勢を戻す全身の連続動作へ変更する。動作の緩急、肩・背骨・首・顎・腕・脚の連動で不気味さと重さを表現する。新規の露骨な流血・臓器表現は追加しない。

モーションは実際の捕食進行に同期する。接近中や移動による中断時に空中で食べ続けず、再開時には最初から正しい姿勢へ遷移する。回復・記憶獲得は実際の捕食完了時の一度だけとし、戦闘・移動・死亡姿勢へ残留しない。

## 不穏UI・成長・戦闘離脱の契約

尽喰廻遊のUIはフラットな管理画面調を避け、暗い肉体感、侵食、傷跡、煤けた層、鈍い光を基調にする。ただし可読性とスマホ操作性は維持し、主要操作を装飾に埋没させない。

プレイヤー入力が数秒間ない場合、戦闘外では怪物が現在地周辺を遅く重く徘徊する。入力再開、戦闘開始、捕食開始、UI操作中は自動徘徊を即時停止する。

再訪禁止は長い説明文で直接説明しない。喰らい尽くした地点は、襲撃候補上で「喰痕」など短い世界内表現と無効状態で示し、必要な情報は視覚状態と短語で伝える。

従来の「肉体の記憶」は、死亡と再生を跨ぐ自キャラクターの転生史として再構成する。各生の開始・死亡、到達した強さ、捕食した特能、戦闘で覚えた動き、喰らった村などを履歴として辿れることを優先する。

手動の技設定・技構成は廃止する。戦った相手の動きと、喰った相手の特能を自動で記録し、自動戦闘が利用可能な学習資産へ変換する。戦闘・捕食の蓄積が次の戦闘選択へ反映され、経験を重ねるほど行動候補と適応度が増える。

戦闘態勢は不可逆ロックにしない。敵との距離を一定時間広げ、追跡圧から抜けた場合は戦闘態勢を解除できる。被弾中や至近距離で瞬時に解除はできないが、後退による離脱意思を尊重する。

接敵時に保持していた入力は無条件に捨てない。単独戦では主対象、複数戦では近い交戦者全体の圧力方向から離れる成分が明確な入力を、そのまま離脱意思として戦闘へ引き継ぐ。接近側へ押し込む持ち越しだけを自動戦闘へ流さず、同じ指を保持したまま逃走方向へ切り返した時点で即座に離脱入力として通す。複数戦では近距離の追跡圧が残る相手を無視して戦闘態勢を解除せず、十分に距離が開いた相手から戦闘参加を外す。

非戦闘から戦闘態勢へ入る表示は一フレームで姿勢を飛ばさない。歩行・徘徊の支持脚と腕位置から、胴体・腕・武器を短いpresentation-onlyの遷移で戦闘poseへつなぐ。Tidebreakの攻撃phase、打点、damage、world座標は変更せず、複数敵の主対象切替でも戦闘態勢そのものを落として再初期化しない。

## 操作性レビューの受入条件

狩り中は「移動」「次に何をするか」「危険状態」「帰還可能か」が同時に読み取れることを優先し、雰囲気のための文言や装飾が操作判断を覆わないようにする。スマホでは右手・左手どちらでも主要操作へ届き、プレイヤーが指で戦場や目的表示を隠し続けない構成にする。

- 初回狩りは、嗅覚 → 接近 → 自動戦闘 → 捕食 → 転生史確認 → 帰還の順を、説明画面を読まなくてもHUD上の一つの主目的として追える。
- 「帰路」は帰還可能条件を満たしていない時に通常の帰還操作に見えず、捕食後は出口方向と残距離が明確になる。
- スワイプ移動とフリック挙動が競合せず、移動を終えたい操作で意図せず別アクションが発動しない。
- 戦闘中は移動入力を要求せず、序・破・急、敵の残り体力、現在の技が一まとまりで読める。
- 戦闘態勢へ入る瞬間に歩行姿勢から戦闘poseへ一フレームで跳ばず、攻撃の打点時刻を変えずに全身の構えが立ち上がる。
- HUDの常設操作は主要3操作までを保ち、設定・連携・履歴など低頻度操作はポーズ内へ退避する。
- 最低44px相当のタップ領域、safe-area、縦長スマホでの下端干渉を維持し、重要表示が操作ボタンと重ならない。
- 操作の意味を変える修正には、純粋関数またはDOM契約のテストを追加して回帰を防ぐ。

## 受入確認

- 襲撃カードの主見出しに固有村名が出ず、規模・危険度とその根拠がスマホ幅でも読める。
- 選択した村の建物数・住人数・危険度の根拠が実際の生成結果と一致する。
- 既存セーブ、入村禁止、オフラインのハウジング読み込みを維持する。
- 捕食の主要段階で全身の姿勢が異なり、接近・中断・再開・完了・各怪物形態で破綻しない。
- フラットUIが不穏な世界内表現へ置き換わり、スマホで主要操作の識別性を維持する。
- 戦闘外で数秒放置すると遅い徘徊が始まり、入力や戦闘・捕食で停止する。
- 喰らい済みの村は説明口調の長文ではなく、短い世界内表現と無効状態で判別できる。
- 転生史から各生の死亡・捕食・学習・到達点を確認できる。
- 手動技設定なしで、戦闘した相手の動きと捕食した特能が自動戦闘の学習資産になる。
- 敵から十分に距離を取り続けることで戦闘態勢を解除できる。
- 影響app/packageの高速テストを行い、Ready後のCI・develop統合・DEV公開はIntegrationへ引き渡す。

## 捕食 → 成長 → 次の獲物の快感ループ

- 1.5秒の捕食進行に、溜め・噛み込み・吸収の全身モーションと光の流れを同期させる。中断では報酬・成長演出を発生させない。
- 捕食成立時は身体の解放動作、足元の衝撃波、魂の粒子、音の上昇で山場を作る。回復量、新しい記憶、装着状態、次の形態までの進捗は実際の獲得結果と一致させる。
- 成長演出は移動や戦闘を止めず、獲物の位置・攻撃の可読性を保つ。粒子数と寿命を制限し、動きを減らす端末設定ではカメラの揺れを抑える。
- 成長の余韻から、まだ喰らっていない記憶を持つ獲物の方向と距離へ視線を導く。帰路を選んだ場合は帰還案内を優先し、新規ボタンや強制モーダルを増やさない。
- 既存の回復・記憶・装備・形態・再訪禁止のルールと保存形式を維持し、見た目だけの強さを実ステータス上昇として表示しない。

### 実装と検証（PR #162）

`consume` の一回だけの成功イベントに、ゲーム内時刻と回復量・最大生命増分・記憶の新規獲得・装着状態・獲得前後の記憶数を追加した。保存ポートによる装備反映後の値から表示を生成し、満タン時の偽の回復表示、装備枠が満杯の際の効果発動表示を防ぐ。

Web表示は `feast-state.js` / `feast-effects.js` / `feast-hud.js` に分離。捕食の2回の噛み込みを全身の捻りと噛砕音へ同期し、魂の螺旋吸収から成長の解放姿勢、2重の衝撃波、84粒の魂、局所光、上昇音へつなぐ。3D演出は2.4秒で終了し、オブジェクトを毎回使い回す。回復のみ・記憶獲得・形態解放は色と強さで区別する。ゲーム内時計に従い、入力や戦闘を止めない。

獲得表示後は9秒間、次の獲物の気配を一体だけ案内する。未知の記憶を優先し、食べ終わった獲物と侵入できない聖域内の獲物は除外。方向矢印はカメラ方位に対応するが経路探索ではない。帰路選択・今夜の目的達成・帰還待機・戦闘・捕食中はそちらを優先する。

局所テストでは回復上限、初回/重複獲得、装備枠満杯、形態解放、中断と再開、帰路優先、カメラ方向、実Three.jsリグの足裏/姿勢復帰、粒子上限/寿命/解放、音の重複発火を確認。最新develop f47a61c（キャラ選択非表示と素材追加）を取り込み後、影響範囲のfast検証は198テスト成功、demon buildと生成物検証成功。

この実装環境のCloud Browserは開発用localhostへの接続を `ERR_BLOCKED_BY_CLIENT` で拒否したため、変更後の画面・音・Pixel Fold実機FPSは未確認。Integrationのfocused browser gateへ、縦画面/横画面の獲得表示とHUD干渉、各形態の捕食から移動/戦闘への復帰を引き継ぐ。Ready化はDEV公開完了を意味しない。

## PR #121 の競合修復

最新developの推奨襲撃先、敵の名前・生命、帰路の解放表示、最寄り帰還口を保持する。
転生史と自動成長は本PRの仕様を維持し、旧装着データは保存したまま特能を常時適用する。
キャラ選択の一時非表示と既存モンスター使用も維持する。
無操作4.5秒後に徘徊し、移動量ゼロの画面タッチ中は開始しない。
メニュー・一時停止で無操作時間をリセットし、捕食・戦闘・帰還待機を優先する。
