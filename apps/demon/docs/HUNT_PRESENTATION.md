# 尽喰廻遊: 襲撃先と捕食の表示契約

## 襲撃先の選択

襲撃先は固有の村名ではなく、村の規模と危険度を主情報として選ぶ。規模には実際の建物・住人数、危険度には実際の敵構成に対応する根拠を添える。獲得できる記憶は副情報として残す。表示だけを変更して全候補の規模を同一にしない。

生成村のID、入村履歴、一度入った村への再訪禁止、所有者・輸入村の識別契約は維持する。既存の保存済み候補を壊さずに扱い、読み込んだハウジングは実際の配置を改変しない。

## 捕食モーション

直立したまま顎だけを周期的に開閉する表現を、身を落とす、獲物へ手を伸ばす、引き寄せる、噛み込む、嚥下して姿勢を戻す全身の連続動作へ変更する。動作の緩急、肩・背骨・首・顎・腕・脚の連動で不気味さと重さを表現する。新規の露骨な流血・臓器表現は追加しない。

モーションは実際の捕食進行に同期する。接近中や移動による中断時に空中で食べ続けず、再開時には最初から正しい姿勢へ遷移する。回復・記憶獲得は実際の捕食完了時の一度だけとし、戦闘・移動・死亡姿勢へ残留しない。

## 操作性レビューの受入条件

狩り中は「移動」「次に何をするか」「危険状態」「帰還可能か」が同時に読み取れることを優先し、雰囲気のための文言や装飾が操作判断を覆わないようにする。スマホでは右手・左手どちらでも主要操作へ届き、プレイヤーが指で戦場や目的表示を隠し続けない構成にする。

- 初回狩りは、嗅覚 → 接近 → 自動戦闘 → 捕食 → 記憶確認 → 帰還の順を、説明画面を読まなくてもHUD上の一つの主目的として追える。
- 「帰路」は帰還可能条件を満たしていない時に通常の帰還操作に見えず、捕食後は出口方向と残距離が明確になる。
- スワイプ移動とフリック挙動が競合せず、移動を終えたい操作で意図せず別アクションが発動しない。
- 戦闘中は移動入力を要求せず、序・破・急、敵の残り体力、現在の技が一まとまりで読める。
- HUDの常設操作は主要3操作までを保ち、設定・連携・履歴など低頻度操作はポーズ内へ退避する。
- 最低44px相当のタップ領域、safe-area、縦長スマホでの下端干渉を維持し、重要表示が操作ボタンと重ならない。
- 操作の意味を変える修正には、純粋関数またはDOM契約のテストを追加して回帰を防ぐ。

## 受入確認

- 襲撃カードの主見出しに固有村名が出ず、規模・危険度とその根拠がスマホ幅でも読める。
- 選択した村の建物数・住人数・危険度の根拠が実際の生成結果と一致する。
- 既存セーブ、入村禁止、オフラインのハウジング読み込みを維持する。
- 捕食の主要段階で全身の姿勢が異なり、接近・中断・再開・完了・各怪物形態で破綻しない。
- 影響app/packageの高速テストを行い、Ready後のCI・develop統合・DEV公開はIntegrationへ引き渡す。

## 捕食 → 成長 → 次の獲物の快感ループ

- 1.5秒の捕食進行に、溜め・噛み込み・吸収の全身モーションと光の流れを同期させる。中断では報酬・成長演出を発生させない。
- 捕食成立時は身体の解放動作、足元の衝撃波、魂の粒子、音の上昇で山場を作る。回復量、新しい記憶、装着状態、次の形態までの進捗は実際の獲得結果と一致させる。
- 成長演出は移動や戦闘を止めず、獲物の位置・攻撃の可読性を保つ。粒子数と寿命を制限し、動きを減らす端末設定ではカメラの揺れを抑える。
- 成長の余韻から、まだ喰らっていない記憶を持つ獲物の方向と距離へ視線を導く。帰路を選んだ場合は帰還案内を優先し、新規ボタンや強制モーダルを増やさない。
- 既存の回復・記憶・装備・形態・再訪禁止のルールと保存形式を維持し、見た目だけの強さを実ステータス上昇として表示しない。
