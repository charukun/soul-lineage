# 尽喰廻遊 — 選択できる狩る姿

## 霧白静刃 / Kirishiro Shizuha

ユーザー添付動画 `1000003106.mp4` の操作キャラクターを最初の外見参照とし、現在はRepositoryの正式なキャラクターリファレンス `docs/characters/references/kirishiro-shizuha/` をデザイン基準とする。

キャラクター名は **霧白静刃（きりしろ しずは / Kirishiro Shizuha）**。銀白の長髪、黒衣、花飾り、大鎌を特徴とする。

参照IDは `kirishiro-shizuha`。既存プロファイルとの互換性を維持するため、セーブ内の外見ID `silver-reaper` は変更しない。ユーザー向け表示やデザイン文書では `silver-reaper` や旧仮称「白銀の鎌姫」を正式名として表示しない。

動画はモデルデータを含まないため、現在の尽喰廻遊Adapterは既存MasterCharacterの顔・リグを利用し、髪束・衣装の層・背面・花飾り・鎌のジオメトリを別途実装している。Character WorkshopのCURRENT MASTERや監査済み量産presetには登録しない。

### 受入条件

- タイトルと「肉体」からキャラクターを選択し、姿を確認できる。
- 既存の魔物と霧白静刃を最初から選べる。選択を既存プロファイルへ保存する。
- 旧セーブの `silver-reaper` 選択は霧白静刃としてそのまま解決される。
- 旧セーブは現在の魔物で開始し、記憶・形態・HP・入村履歴は選択によって変わらない。
- 選択がタイトル・狩り・次の狩り・再起動へ反映される。
- 髪・衣装・鎌は移動と既存の戦闘poseに追従し、捕食中も表示が破綻しない。
- 新たな攻撃判定・解放条件・動画のコンボルールは追加しない。
- アプリ間importと共有モデルの複製を避け、現在のMasterCharacter配信経路を再利用する。
- モデル取得失敗を選択成功と表示せず、現在のキャラで続行・再試行できる。

Ready PRをIntegrationへ引き渡し、CI監視とDEV公開は既存Integrationが行う。

## 検証と引き渡し

- 既存実装では影響範囲fast検証、workspace境界・構文・demon buildを通過済み。
- 実際のSHINO_reviewリグでも局所チェックを実施し、移動・戦闘pose・捕食・死亡時の有限変換、武器の手への追従、元モデルの非変更を確認済み。
- 継続CI用のリグfixtureはdemon内に置き、他appの素材をテストからimportしない。
- CPU上の形状表示で正面・側面・背面を確認し、衣装の貫通と鎌の持ち方を調整済み。
- 実WebGL画面・スマホ実機fps・公開URLの確認はIntegrationのブラウザgateへ引き継ぐ。
- モデルは既存NPCと同じ検証済みtemplateを1回だけ取得。読み込み失敗時は選択確定を無効化し再試行可能。保存済みキャラのモデルが取得できない場合は入村記録を書き込む前に停止する。
