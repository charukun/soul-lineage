# 尽喰廻遊 — 選択できる狩る姿

## 銀白の長髪・黒衣・大鎌のキャラクター

ユーザー添付動画 `1000003106.mp4` の操作キャラクターを外見の参照とする。
動画はモデルデータを含まないため、既存MasterCharacterの顔・リグを利用し、
銀白の長髪、黒い短丈ドレス、花飾り、大鎌をdemonの表示Adapterで再現する。
仮の表示名はモデル固有名が提供されていないため「白銀の鎌姫」とする。
正本の参照IDは `video-character-001`、セーブ内の外見IDは `silver-reaper`。
同じ動画の参照資料は `docs/characters/references/video-character-001/` にある。
動画本体・投稿者情報・外部ゲームのUIは配信物へ含めない。

顔・瞳は既存Shino、髪束・衣装の層・背面・花飾り・鎌の寸法は今回の
表示実装で設計したもの。動画から完全に確定できた外形や元モデルの再配布とは扱わない。
Character WorkshopのCURRENT MASTERや監査済み量産presetには登録しない。

### 受入条件

- タイトルと「肉体」からキャラクターを選択し、姿を確認できる。
- 既存の魔物と白銀の鎌姫を最初から選べる。選択を既存プロファイルへ保存する。
- 旧セーブは現在の魔物で開始し、記憶・形態・HP・入村履歴は選択によって変わらない。
- 選択がタイトル・狩り・次の狩り・再起動へ反映される。
- 髪・衣装・鎌は移動と既存の戦闘poseに追従し、捕食中も表示が破綻しない。
- 新たな攻撃判定・解放条件・動画のコンボルールは追加しない。
- アプリ間importと共有モデルの複製を避け、現在のMasterCharacter配信経路を再利用する。
- モデル取得失敗を選択成功と表示せず、現在のキャラで続行・再試行できる。

Ready PRをIntegrationへ引き渡し、CI監視とDEV公開は既存Integrationが行う。

## 検証と引き渡し

- 影響範囲fast検証: 156 tests成功、workspace境界・構文・demon build成功。
- 実際のSHINO_reviewリグでも局所チェックを実施。移動・戦闘pose・捕食・死亡時の有限変換、武器の手への追従、元モデルの非変更を確認。
- 継続CI用のリグfixtureはdemon内に置き、他appの素材をテストからimportしない。
- CPU上の形状表示で正面・側面・背面を確認し、衣装の貫通と鎌の持ち方を調整。
- 今回の環境ではCloud BrowserからローカルURLが拒否され、ローカルChromium取得もタイムアウトした。実WebGL画面・スマホ実機fps・公開URLの確認は未実施。Integrationのブラウザgateへ引き継ぐ。
- モデルは既存NPCと同じ検証済みtemplateを1回だけ取得。読み込み失敗時は選択確定を無効化し再試行可能。保存済みキャラのモデルが取得できない場合は入村記録を書き込む前に停止する。
