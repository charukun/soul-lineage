# 尽喰廻遊: 通常プレイ入力とHUD契約

この文書は尽喰廻遊の通常狩猟中の入力・HUD・操作説明の正本です。2026-09-18 のゲームフロー・バランス刷新依頼により、目標と帰還報酬の読み取りを追加しました。戦闘操作は追加しません。

## 通常狩猟中の能動操作

通常狩猟中にプレイヤーが行うゲームプレイ上の能動操作は **移動だけ** とします。タッチでは狩場を指で滑らせて移動し、入力を離せば停止します。自動戦闘、停止による捕食、距離を取る戦闘離脱、帰還地点で停止する帰還判定を維持します。

例外はポーズ / システムメニュー / 操作説明を開く補助UIだけです。`#swipe-hint` はゲームプレイ操作ではなく任意説明の入口とし、嗅覚、転生史、帰路、走行停止の独立ゲームプレイ操作は要求しません。

- 嗅覚: 狩場へ入った時と必要な再探索時に自動で働く。
- 戦闘: 接近で自動開始し、敵から距離を取る移動で離脱する。
- 捕食: 倒れた獲物のそばで停止すると自動開始し、移動再開で中断する。
- 帰路: 捕食後は最寄りの帰還口を自動案内し、輪の中で停止すると帰還する。ON/OFFボタンは不要。目標達成時または生命が35%未満の時は帰還を優先案内するが、追加の狩りを禁止しない。
- 転生史・記録・音・連携: ポーズ / タイトルへ置く。強化はタイトル / 結果画面で行う。
- 走行停止: 専用ボタンを置かず、通常の次の移動入力で扱う。

走行は指を素早く弾いて離す入力で開始し、次の移動入力まで継続します。歩行後の終端フリックも有効とし、走行方向は指を離す直前の弾き方向へ揃えます。入力処理と判定は既存 SwipeInput のままです。

## HUDと短い導線

生命状態、現在の目標一つ、その達成数、持ち帰れる戦利品、ポーズ入口を表示します。帰還口の方角・距離・回収額は最初の捕食後から自動表示します。村名、LIFE / NIGHT、特能総数、写し総数のダッシュボードは復活させません。

操作補助は説明専用の斜めサイドガイドへ一本化します。初回の `#first-hunt-guide` は「移動」「自動戦闘」「停止して捕食」を3.2秒程度の短文で一動作ずつ示し、長文を常設しません。捕食後の `#return-hint` は左側の compact guide として帰還口の方角・距離・停止指示を表示します。`#swipe-hint` から開く「動きかた」は中央 `#sheet` を使わず、右端の非モーダル guide で「滑らせる → 移動」「何もしない → 徘徊」「敵から離れる → 戦闘離脱」を短く示します。戦闘結果など瞬間フィードバックは `#toast`、設定・転生史・結果・選択は `#sheet` の責務を維持します。

目標の表示は `HuntFlowUi` に一本化します。旧 first-hunt director / FeastHud / movement-only automation を同時起動しません。初回2体の帰還から、鐘番・猟師・鍛冶師・術師・守護騎士へ進む目標と、死亡後の近場での再挑戦を同じ所有者で表示します。

戦闘中は、敵生命に加えて **序・破・急の現在phaseと現在行動名を一まとまりで表示します**。現在行動名とphaseは値が変わった時だけ遷移し、同値の連続更新では再アニメーションしません。既存 combat-readout-flow を維持し、`prefers-reduced-motion` を尊重します。

## 帰還・死亡・中断

戦利品は狩りの間だけ未確保として保持し、実際の帰還口での停止を経て精算します。メニューで中断した場合は帰還ではなく abandoned です。死亡・中断では未確保の戦利品だけを失い、既存の特能・写した技・購入済み強化は残します。

結果画面は確保または損失、現在の保有額、購入できる強化、次の目標、再挑戦ボタンを同じ画面に置きます。死亡時の主動線は近場で2体を持ち帰る再挑戦とし、本来の目標へ直接挑む選択も置きます。新しい村IDを正式にclaimし、再訪禁止を維持します。

## Browser verification

隠れた旧操作を force click / DOM click で復活させません。native input で移動、自動戦闘、停止捕食、停止帰還までを検証します。

- `#swipe-hint` から任意の「動きかた」を開いても中央 `#sheet` が開かず、ゲーム画面を塞がない。
- `#scent`、`#dash-stop` は通常HUDで非表示を維持し、`#swipe-hint` は44px以上の説明入口として表示する。
- `#first-hunt-guide` は初回の一動作だけを3.2秒程度で示し、捕食後は `#return-hint` が左側の compact guide として方角・距離・停止指示を示す。
- 結果から通常のタップで強化・次の狩り・死亡後の近場への再挑戦へ進める。
- 戦闘phase、現在行動名、音楽、ポーズ、WebGL2、native movement、console/network診断を維持する。

## 受入条件

- 狩場へ入ってから捕食し帰還するまで、ポーズを除いて移動だけで完遂できる。
- 通常HUDに嗅覚・肉体・帰路・走行停止の常設操作ボタンがない。
- 長文の初回説明が常設されず、目的・報酬・次の行動は判断できる。
- 自動戦闘、移動離脱、停止捕食、再訪禁止、既存保存データの互換性を維持する。
- 成長・報酬・確定特能の更新は `docs/demon/HUNT_LOOP.md` の今回依頼範囲に限定する。
- タップ領域、safe-area、キーボード / スクリーンリーダー向け意味付けを維持する。
