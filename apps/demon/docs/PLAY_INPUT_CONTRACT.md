# 尽喰廻遊: 通常プレイ入力とHUD契約

この文書は尽喰廻遊の通常狩猟中の入力・常設HUD・操作説明についての正本です。`docs/PLATFORMS.md` の「操作説明の集約」と「コンシューマ向けゲームUI」を、尽喰廻遊へ具体化します。

## 通常狩猟中の能動操作

通常狩猟中にプレイヤーが行うゲームプレイ上の能動操作は **移動だけ** とします。タッチでは狩場を指で滑らせて移動し、入力を離せば停止します。既存の自動戦闘、停止による捕食、距離を取る戦闘離脱、帰還地点で停止する帰還判定は維持します。

例外はポーズ / システムメニューを開く操作だけです。嗅覚、転生史、帰路、走行停止を通常HUDの独立した能動操作として要求しません。

- 嗅覚: 狩場へ入った時と必要な再探索時に自動で働き、獲物の存在・方向は世界内表示と短い一時表示で伝える。
- 戦闘: 接近で自動開始し、敵から距離を取る移動だけで離脱意思を伝える。
- 捕食: 倒れた獲物のそばで停止すると自動開始し、移動再開で中断する。
- 帰路: 捕食後は最寄りの帰還口を自動案内し、帰還口の輪の中で停止すると帰還する。帰路のON/OFFボタンを要求しない。
- 転生史・記録・音・連携: ポーズ / 結果画面へ退避する。
- 走行停止: 専用ボタンを置かず、通常の移動入力を離す / 次の移動入力で扱う。

## 常設HUD

通常時に常設してよい情報は、瞬間判断に必要なものへ限定します。

- 生命状態の最小表示
- 警戒状態の圧縮表示
- 必要時の現在目的を示す短い世界内マーカー
- ポーズ / システムメニュー入口

村名、LIFE / NIGHT番号、捕食数、特能数、写し数、操作方法の文章、帰還方法の文章、初回狩りの段階説明は常設しません。これらはポーズ、結果画面、必要時だけ出る短い一時表示、または世界内表現へ移します。

戦闘中だけ、敵生命と戦況判断に必要な最小情報を一時表示できます。序破急や現在技を表示する場合も、操作要求に見えるボタンや長文説明へしません。

## 初回導線

初回狩りも説明文をHUDに常駐させません。プレイヤーが移動するだけで、接近、自動戦闘、停止捕食、帰還まで到達できることを優先します。

初見補助が必要な場合は、以下のいずれかに限定します。

1. 最初の数秒だけ表示する「滑らせて移動」の短い一時表示
2. 現在対象へ注意を向ける世界内マーカー
3. ポーズ内の「動きかた」から任意で開く操作説明

「まず○○を押す」「○○してください」のように次のボタン操作を要求する常設チュートリアルは使用しません。

## 受入条件

- 狩場へ入ってから捕食し帰還するまで、ポーズを除いて移動操作だけで完遂できる。
- 通常HUDに嗅覚・肉体・帰路・走行停止の常設操作ボタンがない。
- 初回狩りの説明文が常設HUDに残らない。
- 捕食後は帰還口が自動案内され、ボタン切替なしで帰還できる。
- 転生史・記録・音・連携など低頻度操作はポーズ / 結果画面から利用できる。
- 自動戦闘、移動による戦闘離脱、停止捕食、再訪禁止、保存形式、成長・学習のルールは変更しない。
- タッチ端末の最低タップ領域、safe-area、キーボード / スクリーンリーダー向け意味付けを維持する。
