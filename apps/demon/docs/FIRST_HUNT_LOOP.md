# 尽喰廻遊 初回捕食ループ改善

## 目的

初回プレイで説明を読む時間よりも、獲物を見つけて喰い、身体・能力が変わり、その変化を使って次の獲物を選ぶ時間を優先する。

## 実装範囲

- 初回ガイドを画面占有型から状況依存の短い誘導へ縮小する。
- 初回開始地点の近傍に、最初の捕食対象が明確に見える状態を作る。
- 最初の捕食直後に、獲得した特性・能力を短く強く提示する。
- 獲得能力を直後に使える行動機会を作り、「喰ったからできる」を体験させる。
- 2体目は異なる価値を持つ候補から選べるようにし、次の獲物選びをゲーム判断へ変える。
- 狩り中のUIは現在の獲物・主要アクションを優先し、常時表示情報を減らす。

## 受入条件

1. 新規プレイヤーが開始から45秒以内を目安に最初の捕食へ到達できる導線になっている。
2. 初回捕食後、獲得した変化が数値一覧ではなく短い結果表示で理解できる。
3. 捕食後60秒以内に、獲得した能力に紐づく行動を一度試せる。
4. 2体目の候補は少なくとも2種類あり、得られる価値が見分けられる。
5. 初回ガイドは狩り画面を大きく遮らない。
6. 既存の保存、系譜、襲撃ルート、共有world契約を壊さない。
7. 変更した尽喰廻遊の局所テストとfast validationが通る。

## 非対象

- main / Productionの変更
- 重い全体E2Eの同期実行
- 既存の共有world・network契約の意味変更
- キャラクター選択機能の再公開
