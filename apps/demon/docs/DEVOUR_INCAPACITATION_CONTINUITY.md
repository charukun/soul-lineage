# 尽喰廻遊: 戦闘不能 → 捕食の演出連続性

## 目的

戦闘で人間が戦闘不能になった瞬間から捕食完了までを、一つの身体状態の連続として見せる。捕食だけを派手にして戦闘不能姿勢と切断せず、Tidebreak の打点・damage・world 座標・捕食成立時刻・報酬規則は変更しない。

## 受入条件

- 戦闘不能は一フレームで横倒しへ飛ばず、直前の戦闘姿勢から短い presentation-only の崩れへ遷移する。
- 倒れた人間は武器・手足・首を脱力させ、捕食開始前と捕食開始直後で身体姿勢が不連続に跳ばない。
- 捕食中の被捕食者は、怪物側の lower / reach / pull / bite / swallow / recover と同じ正規化進行値で引き寄せ・持ち上げ・噛み込み反応・嚥下方向の移動を行う。
- 捕食の二回の bite beat は、怪物の顎・被捕食者の身体反応・既存の音/光の山場を同じ時点へ揃える。
- 捕食を移動で中断した場合は `capturedBy` が解除され、報酬・成長演出を出さず、戦闘不能者は自然に地面の脱力姿勢へ戻る。
- 捕食成立直前に被捕食者が地面へ戻る、直立へ戻る、逆方向へ跳ねる挙動を出さない。成立時のみ既存 `consume` により非表示となる。
- 新規の露骨な流血・臓器表現は追加しない。魂・局所光・既存リング/粒子など非写実的な表現で密度を上げる。
- presentation-only の変更に留め、AI、hitbox、save/schema、捕食時間、移動入力、戦闘結果を変更しない。

## 検証

`sampleDevourMotion` と被捕食者用の純粋なサンプラについて、0〜1 の全域で有限値・段階連続・bite beat・終端保持を局所テストする。Three.js 側は既存の `feast.test.mjs` と対象 app の build/check を維持し、重い全体 E2E は通常実装 WORK では要求しない。
