# 尽喰廻遊: ランダム襲撃・捕食成長契約

## 今夜の村

- プレイヤーに村を選ばせない。狩夜開始時と次の夜の開始時に、未訪問の生成村から毎回ランダムに一つ決定して入村する。
- 既存の入村履歴・再訪禁止・保存失敗時の安全停止は維持する。
- ハウジングJSONの読み込みは保存互換のため残すが、通常の狩夜開始フローに村選択画面を復活させない。

## 捕食

- 倒した獲物が捕食可能範囲にいる場合、捕食を移動・再交戦より優先する。
- 捕食開始後は完了または明示的な移動入力による中断まで、戦闘や別行動へ割り込まない。
- 捕食モーションは従来より十分に長くし、接近、引き寄せ、噛み込み、嚥下、回復の全身動作を読める時間にする。
- 報酬・成長・学習は捕食完了時に一度だけ確定する。

## 警戒度

- 生命ゲージ直下の全村共通の警戒度ゲージを廃止する。
- 目撃者数に応じて全体警戒度を蓄積する仕組みと、警戒度を条件に討伐騎士を追加する仕組みも廃止する。
- 個々の村人が怪物を視認して逃げる、接近した敵が戦闘に入る、といった局所AIは維持する。

## 怪物の成長

- 各狩夜の開始時、怪物は小さく弱い状態から始める。
- 捕食完了ごとにその夜の `meals` を増やし、外見サイズと戦闘補正を段階的に上げる。
- サイズは早い段階で成長を実感できる曲線にしつつ上限を設け、巨大化して村・カメラ・当たり判定を壊さない。
- 永続する転生史・獲得記憶と、その夜だけの摂食成長を分離する。

## 技と人間由来の学習

- 怪物側の序・破・急は怪物固有名を基本とし、汎用戦闘技名をそのまま見せない。
- 村人を捕食した時だけ、低確率でその役割に由来する人間の動きまたは特性を獲得する。
- 獲得した動き・特性は既存の転生史と自動戦闘の学習資産へ保存する。毎回必ず獲得させない。

## 敵モデル

- 戦闘対象の村人は手続き型の簡易モデルを主表示にせず、既存の production character pipeline を優先して表示する。
- 同時表示数には性能上限を残し、遠距離・非交戦NPCだけを軽量フォールバックへ落とす。

## 受入条件

- タイトルから狩夜へ進む時に村選択UIが出ず、未訪問村へ直接入る。
- 次の夜でも村選択UIへ戻らない。
- 捕食が従来より長く、捕食中に別の戦闘へ割り込まない。
- 生命ゲージ以外の全体警戒ゲージがなく、全体警戒値による討伐騎士出現もない。
- 0食時が最小・最弱で、捕食のたびに視覚サイズと実戦闘補正が上がり、上限を超えない。
- 怪物固有の技名が表示される。
- 捕食時の人間由来学習が確率判定され、獲得時だけ転生史へ残る。
- 近距離の戦闘対象が production character model で表示される。
