# じんく廻遊: 生還と全ロスト

2026-09-18 の追加要件。既存の狩り・帰還フローを次の契約へ更新する。

- 死亡時はこの生の成長・特能・写した技・購入済み強化・確保済み／未確保戦利品・章進行を全て失う。訪問済み村の記録と設定は保持し、報酬の二重精算や再侵入を許さない。生還では成果を保持できる。
- 最初から種族を選べ、死亡後に選び直せる。体力・移動・追跡を振り切る条件に種族差を持たせる。生存中の種族切替で危険や育成コストを回避できない。
- 強敵は戦闘で実際に脅威となる。序盤の入口は安全を確保し、奥の強敵を自動狩猟で無条件に優先しない。
- 敵から離れる移動で追跡を振り切れる。離脱後すぐ同じ敵に再拘束されない短い猶予を設け、無敵・無料回復・撃破報酬は与えない。
- 帰還方向の表示を長押しすると帰還口へ自動移動する。手動移動・再入力・一時停止・終了で解除する。壁を抜けず、接敵／被弾の危険を残し、既存の出口内滞在条件を満たして帰還する。
- 無操作から徘徊への移行を短くし、村人を探して接近、戦闘、捕食まで既存の正規経路で行う。手動操作と帰還の指示が優先される。

保存・死亡精算・種族差・敵離脱・自動帰還の中断・自動狩猟を局所テストで確認する。main／Productionは変更しない。
