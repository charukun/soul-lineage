# 宝満叡智

村づくりゲームの正式表示タイトル。既存セーブ互換を守るため、保存データの village id / 内部 world name は今回変更せず、UI・パッケージ表示名を `宝満叡智` に更新する。

## Visual direction

ユーザー提供のキービジュアルを方向性の基準とする。羊毛・フェルト・手仕事感、明るい空、生活感のある小さな村、住人が自律して暮らしている密度感を参照する。画像そのものをゲーム背景として直貼りする用途ではない。バイナリをゲーム本体へ同梱せず、描画・モデル・UIの制作基準として扱う。

## Village information HUD

- 常設HUDの数値は、アイコンだけで意味を推測させない。日本語ラベルと値を同時に表示し、アイコンは補助に留める。
- 初期表示は季節・天候・時刻と、年数・人口だけの短い要約にする。詳しい村情報はタップで展開する。
- 展開時は「暮らし」と「資材」を分ける。「暮らし」では住人・受入目安・寝床・守り・食事を優先し、プレイヤーが次の行動を判断できる値にする。
- 暮らし・資材のアイコンは意味の違う項目で同じ図柄を使い回さない。住人・受入目安・寝床・守り・食事・施設、および各資材はそれぞれ判別できる専用シルエットを持つ。
- アイコンは紙面になじむ低彩度の多色を使い、木・石・食料・薬草・鉄など素材の性格を色でも補助する。ただし色だけを識別手段にせず、日本語ラベルと形状の違いを残す。
- 資材は在庫のあるものを日本語名と数量で表示する。在庫がない場合も空欄にせず、その状態が分かる文言を表示する。
- Pixel Fold級の縦長モバイルでは、HUDを必要以上に縦へ伸ばさず、ゲーム画面の視認面積を優先する。
- 通常プレイHUDとそこから開く主要メニューに、Webページのような縦スクロール領域・内部スクロールバー・ダッシュボード型カード一覧を使わない。情報量が一画面を超える場合は、ゲーム内のタブ / ページ送り / 明示的な切替で分割する。
- 村情報の展開面は「暮らし」「資材」を同時に縦へ積まず、どちらか1ページだけを表示する。資材は固定セル数のページ送りとし、スワイプやホイールで一覧を流させない。
- 汎用Material Design風の四角いツールボタン、均一カード、アプリ設定画面のような配置を避ける。羊毛・フェルト・木・刺繍を思わせるゲームHUDとして、世界を隠さない小さな札・メダリオン・タブへ役割分離する。
- HUDを開いても世界が主役のままであること。Pixel Fold級縦画面では、展開面を画面高のおおむね4分の1以内へ収め、ゲーム視界を大きく残す。

## Tent and facility rules

- `shape: tent` は居住用途だけに使う。一般住人用の `tent`、村長用の `mayor`、専属護衛の住居 `guardhome` 以外の仕事・守り施設へテント外観を流用しない。
- テント外観は、ライセンス・immutable provenanceを記録した artist-authored の伝統的yurt実メッシュを使う。円形壁＋明確に先細る円錐屋根＋正面入口が遠景でも読めること。箱型・平屋根に見える候補は採用しない。runtime primitiveで完成シルエットを自作しない。
- モバイル俯瞰で建物の自己影が縞状にちらつかないこと。常時の微小カメラ自動回転でエッジを揺らさず、静止時は画面も静止する。
- 俯瞰用OrthographicCameraでは、カメラの高度そのものを建物LOD距離に使わない。画面中央の地表フォーカスからの水平距離で判定し、近景のテント・家・施設をbounding-box proxy（豆腐）へ置換しない。
- `carpenter`、`guardpost` を含む作業・警備施設は、用途が読める恒久施設として描画する。居住テントの外観で代用しない。
- 一般の `tent` は住人用住居として人口容量を持ち、室内へ家具を置けるハウジング対象を維持する。セーブ上の kind / footprint は互換維持し、既存村も新しい外観へ置き換わる。

## Housing rules

- NPC住居は原則見学専用。ただし一般住人用の `tent` は初期ハウジング対象として家具の追加・移動・撤去を許可する。
- NPCは自分の住居を自律的に整える。新しいNPCにはまず `土の寝床` を保証する。
- `一族の邸宅` は一族プレイヤー用住居として、プレイヤーがハウジングできる。
- 家具は素材との出会いで段階解放する。初期から高級家具は表示しない。
- 家具はすべて休息・快適・食事・技能・交流のいずれかに実効果を持つ。

## Resident focus

住人追従中は、画面右上に「住人に注目中」と対象名を常時表示する。×で追従解除できる。

## Soundtrack

共通150曲セットの正式な共通呼称は **三界の調べ**、コード上の collection id は `rinne-three-worlds-150-v2`。村では village 48曲 + shared 6曲を利用する設計とする。

現在リポジトリには150曲の実音源バイナリが materialize されていないため、この変更では共通カタログとランタイム契約までを実装し、存在しない音源を捏造しない。元成果物は audition / commercialClearance=false のため、実音源投入時に権利確認も必要。
